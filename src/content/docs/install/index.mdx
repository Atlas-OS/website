Atlas Manager is the only way to install Atlas.
It checks your PC and installs Windows and Microsoft Store updates by itself, asks a few questions, then installs Atlas.

Choose the route that matches your PC.

- **You're reinstalling Windows.** Choose **Create an Atlas ISO** on Home to create installation media with Atlas added.
- **You've just installed Windows 11.** Choose **Install Atlas** before adding apps or restoring files.
- **You already use Atlas.** Follow [Update Atlas](/docs/upgrade/).

## What you download

Get **Atlas Manager** (`AtlasManager.exe`) from the [AtlasOS home page](/) or the [latest Atlas release on GitHub](https://github.com/Atlas-OS/Atlas/releases/latest).
To create installation media, Atlas Manager can [download a Windows 11 ISO from Microsoft or use one you already have](/docs/install/iso/#1-windows).
It can also download Atlas for you.

An Atlas ISO is a copy of Microsoft's Windows installation media with Atlas Manager and Atlas added.
Atlas installs after Windows setup and your first sign-in, with the same update and security steps as any other installation.
