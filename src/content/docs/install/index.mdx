## Before you start

- A Windows 11 license for Pro, Pro for Workstations, or Enterprise
- A 64-bit x64 or ARM64 CPU and the matching Windows ISO
- A backup of all important data
- A USB drive if you plan to install from USB

<Callout type="info" title="Note">
  Atlas does not support Windows Home. Change your product key to upgrade Windows to Pro before
  installing Atlas.
</Callout>
