**Atlas Manager is the recommended way to install Atlas.** Built specifically for Atlas, it brings compatibility checks, update preparation, installation choices, and progress into one guided experience. AME Wizard remains available if you prefer it; both apply the same Atlas playbook.

Used Atlas before? See [What changed in Atlas 0.6?](/docs/upgrade/whats-new/) for a quick introduction to the new setup experience.

Atlas 0.6 requires **Windows 11 25H2 (build 26200)**. For a first installation, start with a fresh copy of Windows. If you already use Atlas, check the [upgrade requirements](/docs/upgrade/requirements/) before reinstalling.

## What you are installing

**Atlas Manager** is the app that guides setup and shows your Atlas version. The **Atlas playbook** is the `.apbx` package containing the changes Atlas applies to Windows. Manager downloads or opens this package for you. AME Wizard can apply the same package through its own interface.

Creating an Atlas ISO prepares Windows installation media. Atlas is applied on the destination PC after Windows setup and sign-in, with update and security checks still required.

## After installation

Follow [First setup](/docs/install/setup/) to check drivers, review protection settings, and find the Atlas configuration tools.
