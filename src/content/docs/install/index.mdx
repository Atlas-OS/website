Atlas Manager is the only way to install Atlas.
It checks your PC, installs Windows and Microsoft Store updates, guides you through your choices and then installs Atlas.

Install Atlas on a fresh installation of Windows 11, before you add your own apps and files.
If Atlas is already installed, follow [Update Atlas](/docs/upgrade/) instead.

## What you download

You only need **Atlas Manager**, a single program called `AtlasManager.exe`.
Download it from the [AtlasOS home page](/) or the [latest Atlas release on GitHub](https://github.com/Atlas-OS/Atlas/releases/latest).
Atlas Manager downloads the Atlas package for the latest release itself.

An Atlas ISO is a copy of Microsoft's Windows installation media with Atlas Manager and Atlas added.
Atlas installs after Windows setup and your first sign-in, with the same update and security steps as any other installation.
