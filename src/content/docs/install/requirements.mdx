Before you reinstall Windows, check your Windows edition and back up your files.
Atlas Manager checks your PC on the **Get ready** page.

## Windows release

Atlas installs on public releases of Windows 11 that the Atlas package supports.
Look up your release and build in the [supported releases table](https://github.com/Atlas-OS/Atlas/blob/main/docs/windows-release-policy.md#supported-releases).

- Insider, Release Preview and other preview builds aren't supported.
- A build that Microsoft hasn't listed as a public release yet can't take Atlas until it's listed.
- If your PC has an older Windows 11 release, Atlas Manager can [move Windows to a newer release](/docs/upgrade/windows-release/) before it installs Atlas.

To check your release, press **Win + R**, enter `winver` and read the version and build.

## Windows edition

Windows 11 Home, LTSC and Server editions aren't supported.
Use another edition, such as Pro, Education or Enterprise, that you have a Windows licence for.

Atlas doesn't activate Windows or provide a licence.
Atlas Manager shows whether Windows is activated, but you can install without activation.
To check your edition, open **Settings** > **System** > **About**.

## Start with fresh Windows

Install Atlas on a fresh installation of Windows from Microsoft's installation media, before you restore your apps and files.
If Windows on your PC was installed at least a week ago or already has several apps, Atlas Manager warns that **Windows on this PC looks used**.

If you see this warning, back up your files and reinstall Windows first.
Installing on a used PC is unsupported. Existing apps and settings may stop working, and removing OneDrive stops your files syncing.

For a first install, we recommend [creating an Atlas ISO](/docs/install/iso/). Windows setup runs first, and Atlas Manager guides you through installing Atlas after sign-in.

If Atlas is already installed, you don't need to reinstall Windows to get a newer release.
Follow [Before updating](/docs/upgrade/requirements/) instead.

<Callout type="danger" title="Back up before reinstalling Windows">
  Reinstalling Windows can erase your files, apps and settings.
  Copy important files to separate storage and check that you can open the backup.
  Save any drive encryption recovery keys and the network driver for your PC.
  Removing Atlas later also means reinstalling Windows.
</Callout>

## Your account

- Sign in with a local account or a Microsoft account that's an administrator on the PC.
  Atlas can't be installed from a work or school (Microsoft Entra ID) account.
- Keep User Account Control (UAC) turned on.
- Don't use the built-in Administrator account.
  Sign in with another administrator account instead.

## Have these ready

- **An internet connection that isn't metered**, over Wi-Fi or Ethernet.
  Atlas Manager needs it to update Windows and download Atlas, and Atlas needs it while it installs software.
- **A power supply.**
  Keep laptops plugged in until installation finishes.
- **Free storage** for Windows updates and the installation files.
- **No other antivirus software.**
  Antivirus apps other than Microsoft Defender can block installation, so uninstall them first.
- **A USB drive**, if you're reinstalling Windows from USB.
  Creating installation media erases that drive.

## What Atlas Manager checks

| Check | What it needs |
| --- | --- |
| **Permission to install** | Atlas Manager runs with administrator permission. |
| **User account** | UAC is on, and the account isn't the built-in Administrator or a work or school account. |
| **Windows compatibility** | A supported edition and public release of Windows 11. |
| **Windows updates** | No updates waiting to install. Atlas Manager installs them for you. |
| **Pending restart** | Windows doesn't need a restart to finish earlier changes. |
| **Other antivirus software** | No antivirus apps other than Microsoft Defender. |
| **Internet connection** | A working connection. |
| **Power supply** | The PC is plugged in. |
| **Windows activation** | Shown for your information. It doesn't stop installation. |

Keep Microsoft Defender's protection on while you prepare Windows.
Atlas Manager tells you which switches to turn off when you reach its **Windows Security** step.

Continue with [Install with Atlas Manager](/docs/install/manager/).
