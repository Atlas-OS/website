Check these requirements before changing your Windows installation.

## Windows compatibility

- **Windows 11 25H2, build 26200**, from an official public release. Windows 10, 24H2, and Insider builds are outside this release's supported installation path.
- Use **Pro, Pro for Workstations, or Enterprise**. Home and LTSC are not supported.
- Use a PC that meets Windows 11's hardware requirements. The Atlas Manager media guide uses **x64 Windows** and a **UEFI** PC; do not use that media for an ARM device.
- Keep a valid licence for the edition you install. Atlas does not activate Windows or provide a Windows licence.

Press **Win + R**, enter `winver`, and check the version and build. You can check your edition in **Settings → System → About**.

## Start with fresh Windows

A first Atlas installation requires a fresh Windows installation from unmodified Microsoft media. Install Atlas before restoring your apps and customisations. A repair installation that keeps your existing apps and settings is not a fresh start.

If you already use Atlas, read [Before upgrading](/docs/upgrade/requirements/). Eligible Atlas upgrades do not require a Windows reinstall, but must meet the Windows build requirement separately.

<Callout type="danger" title="Back up before reinstalling">
  Reinstalling Windows can erase your files, apps, and settings. Copy important files to separate
  storage and check that you can open the backup. Save any drive-encryption recovery keys and
  network drivers you may need. Removing Atlas later also requires reinstalling Windows.
</Callout>

## Have these ready

- **An administrator account** on a PC you own and can modify.
- **Unmetered internet access**, through Wi-Fi or Ethernet, for update preparation and downloads. Save your manufacturer's network driver before reinstalling in case Windows cannot connect.
- **A power supply**. Keep laptops plugged in through updates and installation.
- **Enough free storage** for Windows updates and the installation files. ISO creation also needs working space on a local NTFS or ReFS drive; Manager checks the selected location.
- **A USB drive**, if you are reinstalling from USB. Creating installation media erases that USB drive.

## Let Manager prepare Windows

Atlas Manager checks for incompatible antivirus software, pending restarts, and Windows compatibility. Its preparation step installs recommended Windows updates and updates Microsoft Store and installed Store apps. Resolve any reported problem before continuing.

Leave antivirus protection on while preparing Windows. Manager explains which switches to turn off when you reach the Windows Security step.

Continue with [Install with Atlas Manager](/docs/install/playbook/), or choose the [AME Wizard alternative](/docs/install/ame-wizard/).
