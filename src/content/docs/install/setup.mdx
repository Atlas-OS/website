Restart and sign in to finish installing Atlas.
This page covers what to check before you restore your apps and files.

## Read the completion window

After the restart, Atlas Manager opens and says that Atlas is installed.
It also tells you about anything that needs your attention:

- **Turn your protection back on** lists the Windows Security switches that are still off, if you kept Microsoft Defender.
  Open Windows Security and turn them back on.
- **Microsoft Defender was removed** reminds you that your PC has no antivirus until you install another antivirus app.
- **Some choices didn't take effect** names choices the PC doesn't have as you asked.
  Choose **Open log file** to see why.

If you kept Microsoft Defender, **You're all set** appears only once every protection switch reads on.

## Check protection and updates

Open Windows Security and check that its settings match the choices you made.
See [security settings](/docs/atlas-configuration/security/) for each choice.

If you chose **Install updates myself**, open Windows Update regularly to install updates.
Update notifications stay on.
Atlas also turns off automatic updates for Microsoft Store apps, so update them in Microsoft Store under **Library** > **Get updates**.
See [automatic Windows updates](/docs/atlas-configuration/settings/#automatic-windows-updates).

## Check your drivers

If you chose **Get drivers through Windows Update**, check that your display, network, sound and other devices work.
If you chose **Install drivers myself**, install drivers from your PC, motherboard or device maker.
Follow the [drivers guide](/docs/essential-setup/drivers/).

Hardware tuning is optional.
You don't need to change firmware settings to finish setting up Atlas.

## Find the Atlas folder

The Atlas folder holds the controls for turning Windows features and Atlas settings on or off.
Open it from the shortcut on your desktop or in the Start menu, or enter `%windir%\AtlasDesktop` in File Explorer's address bar.
Start with the [configuration overview](/docs/atlas-configuration/) and change only what you need.

Atlas Manager shows your installed version, checks for new Atlas releases and lets you [report a problem](/docs/faq/report-a-problem/).

## Check Atlas health

In the Atlas folder, open `9. Troubleshooting` and run `Check Atlas Health.cmd`.
It reports what Atlas installed and which of its settings have changed since, without changing anything.
A difference can be a change you made yourself, so read the report before you repair anything.
See [Check Atlas health](/docs/atlas-configuration/troubleshooting/#check-atlas-health).

## If other people use this PC

Accounts you create after installing Atlas get Atlas's user settings the first time they sign in.
Ask each person to sign in and check that everything works for them too.
