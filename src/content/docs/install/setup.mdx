Restart and sign in to finish installing Atlas. Open Atlas Manager and confirm it shows your installed version before restoring apps and personal settings.

## Check protection and updates

Open Windows Security and check that your protection settings match the choices you made during installation. If you chose to keep Defender, check that its protections are back on. If you stopped or abandoned installation, restore the protections you temporarily disabled.

Review your Windows Update choice too. If you disabled automatic updates, make time to check for and install updates yourself. See [Security settings](/docs/atlas-configuration/security/) and [automatic updates](/docs/atlas-configuration/settings/#automatic-updates).

## Check your drivers

If you chose Windows Update drivers, check that your display, network, audio, and other devices work. If you chose manual drivers, install the appropriate drivers from your device or component manufacturer.

Follow the [driver guide](/docs/essential-setup/drivers/) for the order and details. Hardware tuning is optional; you do not need to overclock or change firmware settings to finish Atlas setup.

## Find the Atlas controls

Use **Atlas Manager** to view the installed version, check for Atlas releases, and export diagnostics.

Use the **Atlas folder** on your Desktop or Start menu to change Windows features and Atlas settings. The folder lives at `C:\Windows\AtlasDesktop`. Start with the [configuration overview](/docs/atlas-configuration/) and change only the settings you need.

## Check installation health

In the Atlas folder, open **9. Troubleshooting → Check Atlas Health.cmd**. This read-only check reports installation details and differences between recorded choices and current settings. A reported difference may reflect a change you made yourself; check the output before attempting a repair.
