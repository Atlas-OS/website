An ISO is a file that contains Windows installation media.
Atlas Manager adds Atlas to a copy of Microsoft's ISO.
Mount that copy in Windows to reinstall this PC, or write it to a USB drive to start a PC from it.

Atlas installs on the destination PC after Windows setup and your first sign-in.
That PC still needs an internet connection, Windows and Store updates, and the Windows Security step.
Creating the ISO doesn't install anything on the PC that makes it, or change your original ISO.

## What you need

- **A Windows 11 ISO from Microsoft**, for a [supported release](https://github.com/Atlas-OS/Atlas/blob/main/docs/windows-release-policy.md#supported-releases).
  Atlas Manager can download it from Microsoft.
  If you bring your own ISO, use an unmodified Microsoft image for the destination PC (x64 or Arm64).
  It must contain a supported edition, such as Windows 11 Pro.
- **An Atlas package**: Atlas Manager gets the latest one for you.
- **Free space on a local NTFS or ReFS drive** for the new ISO and its working files.
  Atlas Manager shows how much it needs on the **Create** step.
- **Administrator permission.**
  Windows asks for it when you open ISO creation.
- **A USB drive** sold as 16 GB or more, if you want an installation USB.
  Writing it erases the drive.

## 1. Windows

<span id="1-files" />

On Home, choose **Create an Atlas ISO**.
The flow has three steps: **Windows**, **Setup** and **Create**.

1. Answer **Which PC is this ISO for?** with **This PC** or **Another PC**.
   Atlas Manager uses the answer to suggest the language, edition, account name and network drivers.
2. Under **Windows ISO**, choose **Download from Microsoft**.
   Atlas Manager saves Windows 11 to your Downloads folder, in the language and architecture shown under the button.
   To get another language or architecture, choose **Change** first.
   If you already have a Windows ISO, choose **Choose an ISO file** instead.
3. Atlas Manager gets the latest Atlas package by itself.
   To use a saved package, choose **Change** beside it.

Atlas Manager checks the ISO and the package by itself.
When the check passes, choose **Continue**.
If it finds a problem, the message names it and offers the fix, such as **Download from Microsoft**.

## 2. Setup

The **Setup** step sets up Windows on the destination PC, and when you make your Atlas choices.

- **Windows edition**: for **This PC**, the edition this PC has, if the ISO includes it; otherwise Windows Setup asks.
  Choose **Change** to pick another.
  Select **Accept the Windows licence terms, so Windows Setup doesn't ask** if you want to skip that screen.
- **Local account name**: Windows creates a local account with this name, and you choose its password when you first sign in.
  Windows Setup skips the Microsoft account and privacy screens.
- **Drivers**: for **This PC**, **Include this PC's Wi-Fi and Ethernet drivers** is selected, so Windows can go online straight after it's reinstalled.
  Your Wi-Fi password isn't copied, so you reconnect after reinstalling.
  For another PC, keep its network driver on separate storage in case Windows can't connect.
- **How should drivers be installed?**: **Get drivers through Windows Update (recommended)**, **Install drivers myself**, or **Choose after sign-in** to decide on the destination PC.

Then answer **When do you want to make your Atlas choices?**

| Answer | What happens on the destination PC |
| --- | --- |
| **After sign-in** | After you sign in, Atlas Manager opens and guides you through updates, your choices and installing Atlas. |
| **Now** | You make your choices here and Atlas Manager saves them in the ISO. After you sign in, it updates Windows, then you install Atlas with these choices. |
| **Now**, with **Finish before the desktop opens** selected | Your choices are saved in the ISO. After you sign in, Atlas Manager finishes updates and installation full-screen, before the Windows desktop opens. |

With **Now**, you answer the [same questions as in a normal installation](/docs/install/manager/#4-your-choices) here.
An older Atlas package may only offer **After sign-in**.

**Finish before the desktop opens** still needs your attention: it asks for administrator permission, a network connection and the Windows Security step.
Settings, Windows Security and Store apps work behind it.
**Continue in Windows** lets you leave it whenever no update, installation, media job or restart countdown is running.

## 3. Create

<span id="4-review-and-create" />

The **Create** step shows where the new ISO goes, the space it needs and the space free.
Each earlier step has a card with **Change**.
If you left the edition to Windows Setup, select an edition you have a licence for there.

Choose **Create ISO** and keep Atlas Manager open.
The progress bar lists each stage, from reading the Windows ISO to checking the new ISO.
Wait for **Your ISO is ready** before you use it.

## 4. Choose an installation path

<span id="5-choose-an-installation-path" />

Both paths use the Atlas ISO you created in the previous step.

- [Reinstall without a USB drive](#reinstall-without-a-usb-drive) if you can sign in to Windows on the PC you're reinstalling.
- [Install from a USB drive](#install-from-a-usb-drive) if you want to start the PC from installation media, including when Windows won't start.

### Reinstall without a USB drive

Use this route on a PC that runs an edition Atlas supports.
When you create the ISO, choose the same Windows edition, architecture and installation language as that PC.
Check the [installation requirements](/docs/install/requirements/).

<Callout type="danger" title="Back up your files first">
  **Keep nothing** replaces your Windows installation and removes your files, apps and settings from it.
  Back up your files to a separate drive or cloud storage and check that you can open them.
  Save your network driver there too, along with your recovery key if you use BitLocker.
  If you already have a `Windows.old` folder, back up any files you need from it too.
  Setup can replace that folder.
</Callout>

1. In File Explorer, right-click the Atlas ISO you created and select **Mount**.
   Mounting opens the ISO as a drive under **This PC**.
2. Open that drive and run the `setup.exe` next to the `sources` folder.
   Select **Yes** if Windows asks for permission.
3. Follow Windows Setup until you reach **Ready to install**.
   Select **Change what to keep**, choose **Keep nothing** (shown as **Nothing** on some screens), then select **Next**.
4. Check that **Ready to install** shows your Windows edition and **Keep nothing**.
   Select **Install** and let Windows restart as needed.

If Setup can't run from Windows or can't continue with those choices, [install from a USB drive](#install-from-a-usb-drive).
After Windows Setup finishes, [finish installing Atlas](#5-finish-installing-atlas).

#### Recover files from Windows.old

If Setup creates `Windows.old`, open your Windows drive in File Explorer and go to `Windows.old\Users`.
Open the folder for your old account and copy any files you need to your new account or your backup drive.
Windows removes most of these files after 10 days. [Microsoft's file recovery instructions](https://support.microsoft.com/en-us/windows/deployment/install-upgrade/retrieve-files-from-the-windows-old-folder-after-a-windows-upgrade)

### Install from a USB drive

<span id="5-create-an-installation-usb" />

#### Create the installation USB

Choose **Create a USB drive** on the finished ISO screen.
To use an ISO you already have, choose **Create a USB drive from an existing ISO** on the **Windows** step.
Atlas Manager uses the ISO you just created, or the newest Atlas ISO in your Downloads folder; choose **Change** to use another.

<Callout type="danger" title="Back up the USB drive first">
  Writing the USB permanently erases every file and partition on the selected drive.
  Copy anything you want to keep to another drive before you continue.
</Callout>

1. Connect the USB drive.
   Atlas Manager lists drives as you connect them, and selects the drive when it's the only one it can use.
2. Choose **Create USB drive**.
   Check the drive's name and size in the question, then choose **Erase and create**.
3. Keep the drive connected until **Your USB drive is ready**.
   Atlas Manager checks every file it writes, then ejects the drive.

Atlas Manager uses up to 32 GB of the drive and leaves the rest unused.
The drive starts in UEFI mode, which Windows 11 requires.

<span id="6-install-windows-and-atlas" />

#### Start the PC from the USB drive

1. Back up the files on the PC you want to reinstall.
2. Plug the USB drive into that PC and open its boot menu as it starts.
   The key is often **F12**, **F11** or **Esc**.
3. Select the USB drive and follow Windows Setup.
   Check the destination drive carefully before you change partitions.

After Windows Setup finishes, [finish installing Atlas](#5-finish-installing-atlas).

## 5. Finish installing Atlas

<span id="6-finish-installing-atlas" />

After Windows Setup finishes, sign in and set a password if Windows asks you to.
Connect to the internet.
If Windows can't find your network adapter, install the network driver you saved.

When Atlas Manager opens, follow the [installation guide from Get ready](/docs/install/manager/#3-get-ready).
If the app doesn't open on its own, [download and open Atlas Manager](/docs/install/manager/#2-open-atlas-manager) and make your choices during setup.
With **Finish before the desktop opens**, Atlas Manager skips the **Your choices** step and uses the choices saved in the ISO.
Restart when installation finishes, then follow [First setup](/docs/install/setup/).

## If media creation fails

A failed job says what happened and offers **Try again**.
When nothing on the page fixes it, **Send a report**, **Export diagnostics** and **Open log folder** appear under the message.
Your original ISO stays unchanged.
A USB drive that didn't finish can't be used to install Windows; create it again.

If it keeps failing, see [Report a problem](/docs/faq/report-a-problem/).
