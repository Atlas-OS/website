Atlas Manager can make a copy of a Windows 11 ISO with Atlas added, then write it to a USB drive.
Use it to reinstall Windows with Atlas on this PC or another one.

<Callout type="warning" title="Before reinstalling Windows">
  Try the ISO in a virtual machine before using it on a PC, and back up your files before you reinstall Windows.
</Callout>

Atlas installs on the destination PC after Windows setup and your first sign-in.
That PC still needs an internet connection, Windows and Store updates, and the Windows Security step.
Creating the ISO doesn't install anything on the PC that makes it, or change your original ISO.

## What you need

- **A Windows 11 ISO from Microsoft**, for a [supported release](https://github.com/Atlas-OS/Atlas/blob/main/docs/windows-release-policy.md#supported-releases).
  Choose Microsoft's [x64 download](https://www.microsoft.com/software-download/windows11) or [Arm64 download](https://www.microsoft.com/software-download/windows11arm64) for the PC you will install on. The ISO must contain at least one edition other than Home or LTSC.
  Media with its own answer file or setup folder is refused.
- **An Atlas package**: Atlas Manager can download the latest one for you.
- **Free space on a local NTFS or ReFS drive** for the new ISO and its working files.
  Allow five times the size of the source ISO, plus twice the unpacked Atlas package size and another 4 GiB.
- **Administrator permission.**
  Without it, the page offers only **Relaunch as administrator**.
- **A USB drive** from 8 GiB to 2 TiB, if you want an installation USB.
  Writing it erases the drive.

## 1. Files

On Home, choose **Create an Atlas ISO**.
The flow has four steps: **Files**, **Windows setup**, **Your choices** and **Review**.

1. Under **Windows ISO**, choose your ISO.
   **Download Windows 11 from Microsoft** opens Microsoft's download page.
2. Under **Atlas package**, download the latest package or **Browse** for one you already have (`.atlaspkg`).
3. Under **Save the new ISO to**, choose a new file name.
4. Choose **Check files**.

Atlas Manager checks the Windows release, the editions in the ISO and the free space.
When the check passes, choose **Continue**.

## 2. Windows setup

Enter a **Local account name**.
Windows setup creates a local account with this name, so you don't need a Microsoft account, and asks you to choose its password the first time you sign in.
The ISO skips the licence, Microsoft account and privacy screens in Windows setup, and turns off optional data sharing and personalised offers.

Answer **Which PC will you reinstall Windows on?**

- **This PC** lets you choose **Include this PC's network drivers**, so Windows can go online straight after it's reinstalled.
  Choose **Use installed drivers**, or **Check Windows Update first** to download matching drivers as well.
  Your Wi-Fi password isn't copied, so you reconnect after reinstalling.
- **A different PC** includes no network drivers.
  Keep that PC's network driver on separate storage in case Windows can't connect.

Then answer **How should drivers be installed?** for the destination PC: **Get drivers through Windows Update** or **Install drivers myself**.

## 3. Your choices

Answer **How do you want to set up Atlas?**

| Mode | What happens on the destination PC |
| --- | --- |
| **Make Atlas choices after sign-in** | After you sign in, Atlas Manager opens and guides you through updates, your choices and installing Atlas. |
| **Make Atlas choices now** | You make your choices here and Atlas Manager saves them in the ISO. After you sign in, it guides you through updates, then you install Atlas with these choices. |
| **Finish setup before the desktop** | Your choices are saved in the ISO. After you sign in, Atlas Manager finishes updates and installation full-screen, before the Windows desktop opens. |

With the second and third modes, you answer the [same questions as in a normal installation](/docs/install/manager/#4-your-choices) here.
An older Atlas package may only offer **Make Atlas choices after sign-in**.

**Finish setup before the desktop** still needs your attention: it asks for administrator permission, a network connection and the Windows Security step.
Settings, Windows Security and Store apps work behind it.
**Continue in Windows** lets you leave it whenever no update, installation, media job or restart countdown is running.

## 4. Review and create

**Review ISO** shows one card for each step, with a **Change** link, and lists the editions the ISO includes.
Only supported editions are included.
During Windows setup, choose an edition you have a Windows licence for.

Choose **Create ISO** and keep Atlas Manager open.
A checklist shows each stage, from **Checking your Windows ISO** to **Checking the new ISO**.
Wait for **Your ISO is ready** before you use it.

## 5. Create an installation USB

Choose **Create installation USB** on the finished ISO screen.
To use an ISO you already have, choose **Create a USB from an existing ISO** on the first ISO screen.

1. Connect a USB drive, then choose **Refresh** and select it.
2. Choose **Review USB** and check the drive's model, capacity, volumes and serial number.
3. Copy anything you want to keep to another drive.
   Select **I understand that everything on this USB drive will be erased**, then choose **Erase and create USB**.
4. Keep the drive connected until **Your USB is ready**.
   Atlas Manager checks every file it writes.
5. Choose **Eject USB** before you unplug the drive.

<Callout type="danger" title="The selected USB drive is erased">
  Writing the USB permanently removes all files and partitions on it.
  Atlas Manager uses up to 32 GB of the drive and leaves the rest unused.
  The drive works on PCs that start in UEFI mode, which Windows 11 requires.
</Callout>

## 6. Install Windows and Atlas

Back up the files on the PC you want to reinstall.
Plug the USB drive into that PC and start it from the drive using its boot menu, often opened with F12, F11 or Esc as the PC starts.
Check the destination drive carefully before you change partitions.

After Windows setup, sign in and choose a password for the local account.
Atlas Manager opens.
Connect to the internet; if Windows has no network adapter, install the network driver you saved.

Then follow the [installation guide](/docs/install/manager/) from **Get ready**.
With **Finish setup before the desktop**, the **Your choices** step is skipped because your choices are already saved.
Restart when installation finishes, then follow [First setup](/docs/install/setup/).

## If media creation fails

A failed or cancelled job shows a bar with **Open log folder** and the diagnostic buttons.
Your original ISO stays unchanged.
A USB drive that didn't finish can't be used to install Windows; create it again.

If it keeps failing, see [Report a problem](/docs/faq/report-a-problem/).
