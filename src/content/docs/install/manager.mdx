Start with a fresh installation of Windows 11 that meets the [installation requirements](/docs/install/requirements/).
If Atlas is already installed, follow [Update Atlas](/docs/upgrade/) instead.

Atlas Manager installs Atlas in four steps: **Get ready**, **Your choices**, **Windows Security** and **Install**.
It checks your PC and updates Windows by itself.
You answer a few questions, turn off four Windows Security switches and start the installation.

## 1. Start from a fresh installation of Windows

For a first install, we recommend [creating an Atlas ISO](/docs/install/iso/).
If you're installing Windows separately, back up your files and save the network driver for your PC.
Then install a supported edition of Windows 11 from Microsoft's installation media, following Microsoft's [clean installation instructions](https://support.microsoft.com/en-us/windows/deployment/install-upgrade/reinstall-windows-with-the-installation-media).
Check the destination drive carefully before you delete any partitions.
Finish Windows setup and sign in.

## 2. Open Atlas Manager

Download `AtlasManager.exe` from the [AtlasOS home page](/) or the [latest Atlas release](https://github.com/Atlas-OS/Atlas/releases/latest) and open it.
Save your work first: apps may close while Windows updates, and your PC restarts during setup.
On Home, choose **Install Atlas**, then **Yes** when Windows asks whether to let Atlas make changes.

If Windows on your PC has been in use for a while, Home recommends reinstalling it with an Atlas ISO.
**Install Atlas** then asks **Install Atlas on this PC?**, because apps and settings you already have may stop working and Atlas removes OneDrive.
Back up your files before you choose **Install anyway**.

## 3. Get ready

**Get ready** checks your PC, downloads Atlas, and installs Windows and Microsoft Store updates by itself.
When everything is done, it moves on to **Your choices**.

Get ready needs you only in these cases:

- **A check needs attention.**
  The check says what's wrong and offers the Windows setting that fixes it, such as **Open installed apps** for other antivirus software.
  Fix it, then choose **Check again**.
  See [what Atlas Manager checks](/docs/install/requirements/#what-atlas-manager-checks).
- **Your PC needs to restart.**
  Atlas Manager counts down 60 seconds, then restarts.
  To save your work first, choose **Restart later**, then **Restart now** when you're ready.
  After you sign in, Atlas Manager opens again and carries on.
- **Windows needs a newer release.**
  A card at the top of the page asks you to accept Microsoft's licence terms with **Accept and update**.
  See [Move Windows to a newer release](/docs/upgrade/windows-release/).

Optional preview updates and feature updates aren't installed, unless Windows moves to a newer release.
To pause, choose **Stop updating**; Atlas Manager stops after the current step and waits until you choose **Resume updates**.

With **Restart automatically after installing and updating** turned off in **Settings**, nothing counts down: choose **Restart now** when you're ready.

<Callout type="tip" title="Atlas Manager didn't open after the restart?">
  Open Atlas Manager yourself and choose **Continue setup** on Home.
  It carries on where it stopped.
  If updates failed, read the message under **Windows and Microsoft Store updates**, fix the cause, then choose **Try again**.
  See [What if Windows Update fails?](/docs/faq/installation/#what-if-windows-update-fails)
</Callout>

### Drivers

Under the updates, **Drivers** says how Windows gets drivers for your hardware.
To change it, choose **Change**:

- **Get drivers through Windows Update (recommended)** lets Windows find drivers for your hardware.
- **Install drivers myself** stops Windows Update installing drivers, so you get them from your PC or device maker.
  Drivers already installed are kept.

Changing it after Windows has updated runs the updates again.
You can switch later from the Atlas folder; see [driver updates](/docs/atlas-configuration/settings/#driver-updates).

## 4. Your choices

**Your choices** asks every question on one page.
The recommended answers are already selected, and each other answer says what it changes.

| Question | Answers |
| --- | --- |
| **Keep Microsoft Defender?** | **Keep Microsoft Defender (recommended)** or **Remove Microsoft Defender** |
| **Keep Windows' processor protections?** | **Keep processor protections (recommended)** or **Turn off processor protections** |
| **How should Windows install updates?** | **Install updates myself** or **Install updates automatically** |
| **Do you use multiple keyboard languages?** | **Yes, with keyboard shortcuts**, **Yes, with the taskbar selector** or **No, I use one keyboard layout** |
| **Optional extras** | **Turn off hibernation**, **Turn off power saving**, **Turn off virtualisation-based security (VBS)**, **Remove Snipping Tool**, **Remove Microsoft Edge**, **Install a browser**, **Install Atlas Toolbox** and **Install eclean** |

When Windows has only one keyboard layout, Atlas Manager answers the keyboard question for you and doesn't ask it.
The optional extras are at the bottom of the page, where **Turn off power saving** and **Turn off virtualisation-based security (VBS)** start ticked.
Choose **Hide** to fold them away.

These pages explain each choice and how to change it later:

- Microsoft Defender, processor protections and VBS: [security settings](/docs/atlas-configuration/security/)
- Windows updates: [automatic Windows updates](/docs/atlas-configuration/settings/#automatic-windows-updates)
- Keyboard languages: [keyboard languages](/docs/atlas-configuration/tweaks/#keyboard-languages)
- Hibernation and power saving: [power settings](/docs/atlas-configuration/settings/#power-saving)
- Browsers: [choosing a browser](/docs/essential-setup/software/browsers/)
- Atlas Toolbox: [Atlas Toolbox](/docs/toolbox/)

To get Microsoft Edge back, run `Install or Remove Edge.cmd` in the Atlas folder's `1. Software` folder.
Snipping Tool can be installed again from Microsoft Store.

## 5. Windows Security

Microsoft Defender can block the changes Atlas makes, so you turn off four protection switches for the installation.
This is separate from your choice to keep or remove Microsoft Defender afterwards.
Atlas Manager never changes these switches itself.

1. Atlas Manager opens Windows Security at **Virus & threat protection settings**.
   If you close it, choose **Open Windows Security** to open it again.
2. Turn off **Tamper Protection**, **Real-time protection**, **Cloud-delivered protection** and **Automatic sample submission**.

Once all four are off, Atlas Manager comes back to the front and moves on to **Install** by itself.
If Atlas Manager couldn't read a switch, check it in Windows Security, then select the check box that confirms it's off.
When there's nothing to turn off, for example because Microsoft Defender isn't on the PC, Atlas Manager skips this step.

If you keep Microsoft Defender, turn the switches back on after installation finishes.
If you stop before installing, turn them back on straight away.
Home shows which switches are still off.

## 6. Install and restart

The **Install** step shows **Ready to install**, with your choices, each with **Change**, and how long installing usually takes.
**Show details** lists the Atlas package, your Windows version, activation, what Atlas turns off whichever Defender answer you chose, and the installation command.

Save your work and close your apps, then choose **Install Atlas**.
Atlas Manager checks your PC and the protection switches one last time, then installs.
Keep your PC on and plugged in.
If you close the window, installation keeps running; open Atlas Manager again to see the result.

When installation finishes, your PC restarts after a short countdown.
To save your work first, choose **Restart later**, then **Restart now** when you're ready.
To restart yourself after this installation, clear **Restart automatically when installation finishes** before you choose **Install Atlas**.

After you sign in, Atlas Manager opens to say that Atlas is installed.
Continue with [First setup](/docs/install/setup/).

## If installation doesn't finish

Read the message on the **Install** step.
It says what happened and offers the next step, such as **Try again** or **Go to Get ready**.

- If the cause is unexpected, or it stops again, choose **Send a report**, or export diagnostics before you retry or reinstall Windows.
  See [Report a problem](/docs/faq/report-a-problem/).
- If you stop here, turn the protection switches back on in Windows Security, if they're still available.

If the app closed, open it again.
Home offers to finish the installation that stopped, which continues with the same choices.
Don't start a second installation alongside it.

See [What if installation fails?](/docs/faq/installation/#what-if-installation-fails) for more help.
