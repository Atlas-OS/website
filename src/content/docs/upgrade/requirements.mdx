Back up important files before upgrading. Then check both your installed Atlas version and your Windows build.

## Version requirements

| Check | Requirement for Atlas 0.6 |
| --- | --- |
| Installed Atlas version | 0.4.1, 0.5.0, or 0.5.1 |
| Windows version | Windows 11 25H2, build 26200, on a supported edition |
| Preparation | Windows and Store updates complete, with required restarts finished |

Open Atlas Manager to check the installed Atlas version. Press **Win + R** and run `winver` to check Windows. If Manager cannot read the installation state, resolve that error before attempting an upgrade.

<Callout type="warning" title="Still on Windows 24H2?">
  Atlas 0.6 cannot upgrade Atlas on that Windows build. Manager's update preparation does not
  perform Windows feature upgrades. The 24H2-to-25H2 transition for an existing Atlas installation
  needs a validated release-specific path; do not assume the Atlas version list approves it.
  Use the [fresh installation guide](/docs/install/) if no supported transition is documented for your setup.
</Callout>

Other Atlas versions are not declared direct upgrade sources. Check the release notes for your exact version or start with a fresh Windows installation.

## What carries over

The upgrade keeps your files and applications in place and preserves existing Start and taskbar layouts, file associations, and original service backups.

Recorded Atlas configuration choices are reapplied with the new definitions. On older releases, Atlas adopts a previous choice only when the existing settings identify it clearly. Custom changes made outside the Atlas controls may not be preserved.

The Atlas folder and modules are replaced, and current installation options and applicable tweaks are applied. Save any personal files you added to the Atlas folder elsewhere before upgrading.

## PCs with more than one account

Existing accounts receive a settings migration at their next sign-in. Some protected user policies in other accounts may retain their older values. Sign into each account you use after upgrading and check its settings; the installing account's success does not verify every profile.

## Ready to continue?

Download Atlas Manager and read the target release notes on the [Atlas release page](https://github.com/Atlas-OS/Atlas/releases), then follow the [upgrade instructions](/docs/upgrade/upgrade/). You can also use AME Wizard with the target release's `.apbx` package.
