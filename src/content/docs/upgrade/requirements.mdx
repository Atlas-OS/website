# Before upgrading

Check every requirement before you upgrade Atlas.

## Version requirements

- Your system must currently run **AtlasOS v0.5.0**
- **v0.4.1 and older** systems are not direct upgrade sources for the current Playbook
- If an archived upgrade path is not published for your exact version, perform a [fresh install](/docs/install/)

<Callout type="info" title="Check your version">
  [Check your AtlasOS version](/docs/faq/general/#checking-your-atlasos-version) before you continue.
</Callout>

## Required files

- The latest **AME Beta** executable
- The **new Atlas Playbook** (<CodeInline text=".apbx" />) for the version you want to upgrade to

## Backup important data

<Callout type="warning" title="Back up your data">
  Back up important data before you upgrade.
</Callout>

## What gets preserved

- All user files and apps
- Most AtlasOS tweaks and settings

## Known limitations

**Upgrading from 0.5.0<IconArrow />newer 0.5.x releases:**

The current Playbook is designed to preserve user files, applications, and most Atlas folder configuration during supported 0.5.x upgrades.

**Older versions:**

AtlasOS v0.4.1 and earlier may need a fresh install or a specific archived upgrade path. Do not assume AME Beta will show an upgrade option unless the Playbook supports your installed version.
