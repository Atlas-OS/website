Each Atlas release has release notes that say what changed, what it needs and anything to know before you update.
This page tells you where to find them.

## Where to read them

- **Atlas Manager:** when a newer release is out, Home shows **What's new in Atlas** for it.
  Choose **Show all release notes** to read them in full, or **View release notes on GitHub**.
- **GitHub:** every release and its notes are on the [Atlas releases page](https://github.com/Atlas-OS/Atlas/releases).

Atlas Toolbox has its own releases, on the [Atlas Toolbox releases page](https://github.com/Atlas-OS/atlas-toolbox/releases).

## What to check before you update

- Which Windows releases the new release supports, and whether Atlas Manager needs to [move Windows to a newer release](/docs/upgrade/windows-release/).
- Which installed versions it can update from.
  If yours isn't one of them, you need to reinstall Windows.
- Any changes to choices or settings you rely on.

Then follow [Before updating](/docs/upgrade/requirements/).

## Test builds

Before a release, the Atlas team sometimes publishes test builds of Atlas Manager.
A test build shows a bar saying it's a test build, and installs only the Atlas package bundled with it.
Use test builds only to help with testing, and report problems through the channel named in their release notes.
See the [testing guide](/docs/contributing/testing/).
