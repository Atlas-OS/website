# Upgrade guide

Upgrade a supported Atlas installation without reinstalling Windows. The upgrade keeps your files, apps, and most Atlas settings.

<Callout type="tip" title="Quick Summary">
  The current Atlas Playbook supports in-place upgrades from **AtlasOS v0.5.0**. Older Atlas versions
  are not advertised by the current Playbook as direct upgrade sources.
</Callout>

## Requirements

- Your system currently runs **AtlasOS v0.5.0**
- **v0.4.1 and older** systems should follow the [fresh installation guide](/docs/install/) unless a specific archived upgrade path is published for that version
- You have the latest **AME Beta** executable
- You have the **new Atlas Playbook** (<CodeInline text=".apbx" /> or release zip) for the version you want to upgrade to

<Callout type="warning" title="Version Check">
  [Check your AtlasOS version](/docs/faq/general/#checking-your-atlasos-version) before you download
  the new Playbook.
</Callout>
