Atlas Manager can upgrade an eligible Atlas installation without reinstalling Windows. AME Wizard remains an alternative for applying the new playbook.

Coming from an earlier release? Read [What changed in Atlas 0.6?](/docs/upgrade/whats-new/) for the new installation flow, settings migration, and ISO options.

Atlas 0.6 declares **0.4.1, 0.5.0, and 0.5.1** as upgrade sources. Your PC must also run **Windows 11 25H2 (build 26200)**. Having a listed Atlas version does not make an older Windows build eligible.

The upgrade is designed to keep files and apps in place. Atlas configuration is reapplied using the new release's definitions, so review your choices and important settings afterwards.
