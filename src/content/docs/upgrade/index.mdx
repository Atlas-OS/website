Atlas Manager updates an installed Atlas to a newer release without reinstalling Windows.
Your files and apps stay, and you choose whether to keep your Atlas choices or make them again.

When a newer release is out, Atlas Manager's Home page says so and offers an **Update to Atlas** button for it.

## Which installations can update

Two things decide whether Atlas Manager can update your PC:

- **Your installed Atlas version.**
  Each release lists the versions it can update from as `updatableFrom` in its [`atlas.json`](https://github.com/Atlas-OS/Atlas/blob/main/package/atlas.json).
  From any other version, back up your files and reinstall Windows.
- **Your Windows release.**
  It must be one the release supports, as listed in the [supported releases table](https://github.com/Atlas-OS/Atlas/blob/main/docs/windows-release-policy.md#supported-releases).
  If it's older, Atlas Manager can [move Windows to a newer release](/docs/upgrade/windows-release/) as part of the update.

Atlas Manager checks both for you and explains what to do when it can't update.
