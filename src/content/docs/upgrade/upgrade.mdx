# Upgrade process

Follow these steps to upgrade AtlasOS.

## Step 1: Download assets

1. Visit [atlasos.net](https://atlasos.net)
2. Click **Get started**<IconArrow />**Already following the guide?**
3. Download the newest **Atlas Playbook** and **AME Beta**

## Step 2: Launch AME Beta

1. Extract both downloads to your desktop
2. Run <CodeInline text="AME Beta.exe" />
3. If SmartScreen warning: **More info**<IconArrow />**Run anyway** (safe to ignore)
4. Click **Updates**<IconArrow />Update AME Beta if available

## Step 3: Upgrade AtlasOS

1. Drag the downloaded <CodeInline text="Atlas Playbook.apbx" /> file into AME Beta
2. When prompted, select **Upgrade** rather than **Run again**
3. AME Beta will analyze your current installation and apply only the changes required for the new version
4. Follow on-screen instructions and wait until the process completes
5. Your PC will reboot automatically

<Callout type="info" title="How It Works">
  AME Beta compares your installation with the new Playbook and applies only the necessary
  changes. No full reinstall.
</Callout>

## After upgrade

### Check Atlas folder configuration

After a supported 0.5.x upgrade, your apps, files, and most Atlas configuration should remain in place. Open the Atlas folder and confirm the settings you care about are still set as expected:

1. Open the Atlas folder at <CodeInline text="C:\Windows\AtlasDesktop" />
2. Review your settings from the numbered sections (see [Atlas Configuration](/docs/atlas-configuration/))

<Callout type="tip">
  The current Playbook advertises AtlasOS v0.5.0 as its direct upgrade source. Older versions may
  require a fresh install or an archived upgrade path.
</Callout>

## Troubleshooting

### AME Beta doesn't show upgrade option

- Confirm you're on AtlasOS v0.5.0 using the [version check guide](/docs/faq/general/#checking-your-atlasos-version)
- Use the latest AME Beta
- Make sure the Playbook you are using supports upgrading from your installed Atlas version

### Older Atlas versions

AtlasOS v0.4.1 and earlier are not direct upgrade sources for the current Playbook. Follow the [Installation guide](/docs/install/) for a clean reinstall unless an archived upgrade path is published for your exact version.
