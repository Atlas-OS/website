Read [Before upgrading](/docs/upgrade/requirements/) and back up before starting. These steps apply only when both your Atlas version and Windows build are eligible.

## Upgrade with Atlas Manager

1. Open Atlas Manager and allow administrator access when prompted.
2. Check the installed version on Home. Choose **Check again** if the release check has not completed.
3. Read the release notes, then choose **Update to Atlas 0.6.0** when offered.
4. In **Get ready**, let Manager download Atlas 0.6 and resolve the PC checks. If you already have the Atlas 0.6 package (`.apbx`), you can choose **Open package file** instead.
5. Review the driver choice and complete Windows and Store update preparation. Use **Restart and continue**, then **Continue updates** after sign-in, if requested.
6. Review the Atlas options and complete the Windows Security step when Manager asks.
7. Start the upgrade and keep your PC powered on. After it succeeds, restart to complete setup.

The preparation and security steps are explained in [Install with Atlas Manager](/docs/install/manager/#3-update-windows-and-store-apps).

## Check the result

After restarting:

1. Open Atlas Manager and confirm it shows the new installed version.
2. Open `C:\Windows\AtlasDesktop` and review the settings you rely on.
3. Run **9. Troubleshooting → Check Atlas Health.cmd** in the Atlas folder. It reports installed state and settings that differ from recorded choices without changing them.
4. Check Windows Security, Windows Update, Microsoft Store, and your everyday apps.
5. Sign into other accounts you use and check their settings too.

See [Atlas configuration](/docs/atlas-configuration/) for the available controls. If you chose manual drivers, check those as well.

## If the upgrade fails

Use **Export diagnostics** before retrying. Reopen Manager to recover the saved session and follow the reported error. If you opened a saved Atlas package, keep it available; a retry may need the same package and choices.

If the installed version cannot be read, or the installer cannot confirm its result, use [installation troubleshooting](/docs/faq/installation/#what-if-installation-fails) before starting another attempt.
