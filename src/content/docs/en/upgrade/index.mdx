# Upgrade guide

Upgrade Atlas to a newer version without reinstalling. The process keeps your settings and installed applications, and applies the latest optimizations.

<Callout type="tip" title="Quick Summary">
  If you're running AtlasOS **v0.4.1 or later** (Windows 11 24H2 or 25H2), you can upgrade directly to a
  newer version (e.g., v0.5.x) using AME Beta. Clean installs are not required but are still
  recommended.
</Callout>

## Requirements

- Your system currently runs **AtlasOS 0.4.1 or newer** (Windows 11 24H2 or 25H2)
  - **v0.4.0** requires a fresh install to reach v0.5.0
  - **0.3.x** users must perform a fresh install
- You have the latest **AME Beta** executable
- You have the **new Atlas Playbook** (<CodeInline text=".apbx" />) for the version you want to upgrade to (e.g., <CodeInline text="Atlas Playbook 0.5.x" />)

<Callout type="warning" title="Version Check">
  If you're unsure about your current AtlasOS version, check the [FAQ guide](/docs/faq/general/#checking-your-atlasos-version) for
  how to check your version.
</Callout>
