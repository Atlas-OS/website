# Before upgrading

Verify you meet all requirements before upgrading.

## Version requirements

- Your system must currently run **AtlasOS 0.4.1 or newer** (Windows 11 24H2 or 25H2)
- **v0.4.0** requires a [fresh install](/docs/install/) to reach v0.5.0
- **0.3.x** users must perform a [fresh install](/docs/install/)

<Callout type="info" title="Not Sure?">
  See the [FAQ guide](/docs/faq/general/#checking-your-atlasos-version) for how to check your version.
</Callout>

## Required files

- The latest **AME Beta** executable
- The **new Atlas Playbook** (<CodeInline text=".apbx" />) for the version you want to upgrade to

## Backup important data

<Callout type="warning" title="Recommended">
  Back up important data before upgrading.
</Callout>

## What gets preserved

- All user files and apps
- Most AtlasOS tweaks and settings

## Known limitations

**Upgrading from 0.4.x<IconArrow />0.5.x:**

The upgrade doesn't carry over Atlas folder configuration (General Configuration, Interface Tweaks, etc.). Re-apply these settings after the upgrade.

This limitation doesn't apply when upgrading from 0.5.x to later versions.
