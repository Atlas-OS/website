## Quick answers

### What is AtlasOS?

AtlasOS is an open-source modification of Windows that applies privacy, usability, and performance optimizations while keeping functionality and customizability.

### Is AtlasOS safe?

Yes. AtlasOS is open-source and community-reviewed. You can inspect all modifications on GitHub.

### Which Windows versions are supported?

Atlas supports **Windows 11** Pro, Pro for Workstations, and Enterprise.

<Callout type="warning" title="Windows Home Not Supported">
  Atlas does not support Windows Home. Upgrade to Pro by changing your product key.
</Callout>
