# How to report issues

This guide explains how to report issues you find [when testing](/docs/contributing/testing/).

## AME Beta logs

Before reporting, skim your AME Beta logs (located in <CodeInline text="C:\ProgramData\AME\Logs" />) for:

- The <CodeInline text="Output.txt" /> from the latest Playbook
  - Check for errors or logical issues in the scripts
- The <CodeInline text="Log.yml" />
  - Check if there are any errors from AME Beta

If you find anything, include it. **Always post all logs when reporting bugs.** These logs do not contain personally identifiable information except your Windows username.

## Where to report

### If it's the latest release...

Please report to the [Atlas GitHub Issues](https://github.com/Atlas-OS/Atlas/issues). Ensure that you follow the issue template.

### If it's from a GitHub branch...

Report to the <CodeInline text="📘 ┃ playbook" /> channel in [Discord's 'Development' category](https://discord.com/invite/atlasos), or to [Atlas GitHub Issues](https://github.com/Atlas-OS/Atlas/issues). Follow the issue template.

### If it's a preview from our Discord...

Report to the designated <CodeInline text="🧪 ┃ issue-reporting" /> forum channel under the 'Development' category.
