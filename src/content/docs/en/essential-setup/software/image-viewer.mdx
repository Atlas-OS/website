# Image Viewer

## qView

qView is a minimal open-source image viewer. Lightweight with a clean UI. Best if you just want to view images.

```
winget install -e --id jurplel.qView
```

[Download qView](https://interversehq.com/qview/download/)

## IrfanView

IrfanView is a lightweight image viewer that is easy to use while offering many features. Plugins expand functionality. Good for viewing and editing.

```
winget install -e --id IrfanSkiljan.IrfanView
```

[Download IrfanView](https://www.irfanview.com/64bit.htm)

## Nomacs (Preview)

Nomacs is a simple open-source image viewer for viewing and basic editing. The latest official release is outdated; use the latest preview build.

[Download Nomacs](https://github.com/nomacs/nomacs/releases/)

## Microsoft Photos

Microsoft Photos is available on Windows and can be installed from the Microsoft Store. It has a modern UI and integrations with OneDrive and iCloud.

<Callout type="info" title="Codec extensions">
  Microsoft Photos does not support all image and video formats by default. For HEVC video and HEIF
  images, download the HEVC Video Extensions and HEIF Image Extensions from the Microsoft Store.
</Callout>

```
winget install -e --id 9WZDNCRFJBH4
```

[Download Microsoft Photos](https://apps.microsoft.com/store/detail/9WZDNCRFJBH4) (Microsoft Store)

[Download HEVC Video Extensions](https://apps.microsoft.com/store/detail/9NMZLZ57R3T7) (Microsoft Store)

[Download HEIF Image Extensions](https://apps.microsoft.com/store/detail/9PMMSR1CGPWG) (Microsoft Store)
