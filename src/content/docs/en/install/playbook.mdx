# Playbook installation method

Follow these steps in order. The full process (Windows reinstall, updates, Atlas installation) takes about 30–45 minutes. Atlas installation alone takes about 15 minutes. Before continuing, see [who Atlas is for](/docs/faq/installation/#who-is-atlas-designed-for).

## Step 1: Download Windows ISO

You need a clean Windows 11 ISO to reinstall Windows.

<WindowsIsoDownload />

## Step 2: Prepare network drivers (recommended)

You may lose internet after Windows installation if network drivers are missing.

**Download now:**

1. Search for your motherboard or device model + "network drivers"
2. Download the latest drivers
3. Save to a USB drive or external storage

<Callout type="info" title="Can't find drivers?">
  Check your manufacturer's support page or search Device Manager for your
  network adapter name.
</Callout>

## Step 6: Update Windows and Microsoft Store apps

Update Windows and Microsoft Store apps before installing Atlas.

1. **Update Windows:**
   - **Settings**<IconArrow />**Windows Update**
   - Install all updates (including optional updates)
   - If paused, click **Resume Updates**
   - Restart your computer if prompted

2. **After restart (if applicable):**
   - Check **Windows Update** again and install any remaining updates
   - Repeat until no more updates are available

3. **Update Microsoft Store apps:**
   - Open **Microsoft Store**
   - Click **Library** (or search for "Updates")
   - Click **Get updates** to update all apps
   - Wait for all updates to complete

4. **After restart (if applicable):**
   - Open **Microsoft Store** again
   - Check for updates again to confirm everything is current

<Callout type="info" title="Important">
  Update Windows and Microsoft Store apps fully before proceeding. After restart, check both again.
</Callout>

## Step 7: Install AtlasOS

1. **If using Manual Driver Installation:**
   - Run <CodeInline text="Disable Drivers Installation in Windows Update.reg" /> from the extracted Atlas Playbook folder on your desktop
   - Restart your computer

2. **Download AtlasOS:**
   - Open Edge<IconArrow />Go to [atlasos.net](https://atlasos.net)
   - Click **Get started**<IconArrow />**Already following the guide?**
   - Download **Atlas Playbook** and **AME Beta**

3. **Extract files:**
   - Extract both to desktop

4. **Install AtlasOS:**
   - Open <CodeInline text="AME Beta.exe" />
   - If SmartScreen warning: **More info**<IconArrow />**Run anyway** (safe to ignore)
   - Click **Updates**<IconArrow />Update AME Beta if available
   - Drag <CodeInline text="Atlas Playbook.apbx" /> into AME Beta
   - Follow on-screen instructions

<Callout type="warning" title="AME Beta deleted?">
  Add it as an exclusion in Windows Security or disable Real-time protection temporarily.
</Callout>
