# Installation requirements

Verify you have everything below before installing Atlas.

## System requirements

- **Back up all important data** to a safe location:
  - Cloud storage (Google Drive, Microsoft OneDrive, Dropbox)
  - External storage (NAS, portable drive, USB drive)

- Meet the **[Windows 11 system requirements](https://www.microsoft.com/windows/windows-11-specifications#table1)**

- **64-bit CPU (x64) or ARM CPU (ARM64)** - Use x64 Windows ISO for Intel/AMD CPUs, or ARM64 Windows ISO for ARM systems ([check your system architecture](https://support.microsoft.com/en-us/windows/which-version-of-windows-operating-system-am-i-running-628bec99-476a-2c13-5296-9dd081cdd808))

- **Windows edition:** Pro, Pro for Workstations, or Enterprise (Atlas doesn't support Home)

- **Basic familiarity with Windows** – Meet Windows 11 requirements; bypassing them can cause update and game issues

<Callout type="danger" title="Back up your data first">
  Atlas installs by reinstalling Windows. Your current setup will be replaced. Removing Atlas
  requires [reinstalling Windows](/docs/faq/reverting/). Back up important files before you start.
</Callout>
