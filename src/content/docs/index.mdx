## What is AtlasOS?

AtlasOS (also called Atlas) removes unnecessary services, reduces telemetry, and cuts system overhead. Its source is public, so you can inspect every change on GitHub.

### Key features

- **Improve privacy**: Remove telemetry and tracking services
- **Reduce overhead**: Limit background processes and services
- **Keep control**: Enable or disable individual settings and tweaks
- **Inspect every change**: Review the source code on GitHub
