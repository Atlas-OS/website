## What is AtlasOS?

AtlasOS (also called Atlas) is an open-source modification of Windows that removes unnecessary services, reduces telemetry, and optimizes system performance while keeping full functionality. Inspect all modifications on GitHub—the community reviews them.

### Key features

- **Privacy-focused**: Removes telemetry and tracking services
- **Performance-optimized**: Reduces system overhead and improves gaming performance
- **Customizable**: Enable or disable any tweak or setting
- **Open-source**: All code is publicly available and community-reviewed
