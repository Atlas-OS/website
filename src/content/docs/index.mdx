## What is AtlasOS?

AtlasOS, also called Atlas, is an open-source project that configures Windows.
It turns off selected telemetry, removes selected apps and changes interface defaults.
Its source is public, so you can read every change it makes on GitHub.

### Key features

- **Privacy:** Atlas turns off selected Windows telemetry and configures policies to reduce data collection.
- **Less background activity:** Atlas configures services, background apps and power settings.
- **Control:** The Atlas folder lets you turn individual features and settings back on or off.
- **Transparency:** Every script and setting is in the Atlas repository on GitHub.
