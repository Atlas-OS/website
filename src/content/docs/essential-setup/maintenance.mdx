This page covers keeping your Atlas installation clean over time.
Atlas changes Windows when you install it, and apart from scheduled Storage Sense clean-ups it doesn't maintain your PC afterwards.
Temporary files, startup apps and unused software build up on any Windows installation.

## Start with the built-in tools

Windows includes basic maintenance tools. Try these before installing anything.

### Storage Sense

Storage Sense removes temporary files and empties the Recycle Bin on a schedule.
Atlas sets it to clean up temporary files every month.
To change what it cleans and how often:

1. Open **Settings**<IconArrow />**System**<IconArrow />**Storage**
2. Select **Storage Sense**
3. Choose what it cleans and how often

### Disk Cleanup

Disk Cleanup removes temporary files, old Windows Update files, and thumbnails.

1. Press **Win + R**, type <CodeInline text="cleanmgr" />, press **Enter**
2. Select the drive to clean
3. Click **Clean up system files** to include update leftovers

### Startup apps

Programs that start with Windows slow down boot and use resources in the background.

1. Press **Ctrl + Shift + Esc** to open Task Manager
2. Go to **Startup apps**
3. Disable anything you don't need at startup

### Uninstalling software

Open **Settings**<IconArrow />**Apps**<IconArrow />**Installed apps**. Sort by size or install date to find software you no longer use.

## What to avoid

The PC cleaner category has a bad reputation for good reasons. Avoid:

- **Registry cleaners.** They don't make modern Windows measurably faster, and a bad deletion can break software.
- **Invented problem counts.** A scan that reports hundreds of "errors" on a healthy PC is trying to scare you into paying.
- **Bundled installers.** If a cleaner's installer offers a toolbar, a browser, or a second app, close it.

## Third-party tools

Prefer something else? These tools also go further than the built-ins. All of them work on AtlasOS.

### BleachBit

BleachBit is a free, open-source cleaner. It removes junk files and browser data. The interface is minimal and there are no upsells.

<CodeBlock title="Install with winget:" code="winget install -e --id BleachBit.BleachBit" />

[Download BleachBit](https://www.bleachbit.org/)

### CCleaner

CCleaner is the best-known cleaner. The free version works, but decline the bundled offers during installation and expect upgrade prompts. Skip its registry cleaner.

<CodeBlock title="Install with winget:" code="winget install -e --id Piriform.CCleaner" />

[Download CCleaner](https://www.ccleaner.com/)

### Revo Uninstaller

Revo removes software along with the leftover files and registry entries a normal uninstall misses. It's useful for stubborn programs.

<CodeBlock title="Install with winget:" code="winget install -e --id RevoUninstaller.RevoUninstaller" />

[Download Revo Uninstaller](https://www.revouninstaller.com/)

### WizTree

WizTree shows what's using your disk space. It scans in seconds and lists the largest files and folders, so you can decide what to remove.

<CodeBlock title="Install with winget:" code="winget install -e --id AntibodySoftware.WizTree" />

[Download WizTree](https://diskanalyzer.com/)

## A simple routine

Every month or two:

1. Clear temporary files with Storage Sense or a cleaner
2. Review startup apps and disable new entries
3. Uninstall software you no longer use
4. Keep at least 15% of your system drive free
