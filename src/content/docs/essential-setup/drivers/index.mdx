Atlas Manager offers automatic driver installation through Windows Update during preparation. Start there unless you need a specific manufacturer driver or prefer to manage drivers yourself. This guide also helps if a device is missing or does not work after installation.

## When to install drivers manually

Use the device manufacturer's package when:

- Windows Update has not found a working driver.
- A laptop or prebuilt PC needs model-specific features.
- You need a particular driver version to resolve a documented problem.

Manual installation does not automatically improve performance or reduce resource usage. Install the packages your hardware needs and review any optional companion software.

## Find the right package

1. Identify your exact PC or motherboard model. For an individual device, open **Device Manager**, then its **Properties → Details → Hardware Ids** if the name is unclear.
2. Use the manufacturer's official support page. For laptops and prebuilt PCs, start with the PC manufacturer's model page.
3. Match the package to your device and Windows architecture. Choose a supported Windows 11 driver and follow its installation instructions.
4. Restart when requested, then test the device before installing another version.

Avoid bulk driver-updater utilities and downloading every version listed for a device. If you have no internet connection, transfer the correct network driver from another PC; see [network drivers](/docs/essential-setup/drivers/network/).

## Switch to automatic installation

Open <CodeInline text="C:\Windows\AtlasDesktop" /><IconArrow /><CodeInline text="2. Drivers" /><IconArrow /><CodeInline text="Drivers from Windows Update" /> and run <CodeInline text="Enable Drivers from Windows Update.reg" />. Restart afterward so Windows can apply the driver policy.

Then open **Settings → Windows Update** and check for updates. Review **Advanced options → Optional updates** for additional drivers if needed. To return to manual control, use <CodeInline text="Disable Drivers from Windows Update.reg" /> in the same folder. This changes future update behavior; it does not uninstall existing drivers.

See [Microsoft's driver-update guidance](https://support.microsoft.com/en-us/windows/hardware/drivers/automatically-get-recommended-and-updated-hardware-drivers) for the current Windows steps.

If the Atlas folder is missing, follow <AtlasFolderRestoreLink />.

## Which drivers do I need?

Install only the drivers for hardware in your system:

- **Graphics (GPU/iGPU):** Display output and gaming
- **Audio:** Sound from speakers or headphones
- **Wi-Fi/Network:** Internet connectivity
- **Bluetooth:** Wireless peripherals (only if you use them)
- **Chipset:** System stability and performance

<Callout type="warning" title="Multiple Graphics Cards">
  If you have both integrated and dedicated graphics (e.g., Intel CPU with NVIDIA GPU), install
  drivers for both so you can switch between GPUs.
</Callout>

<Callout type="tip">
  Restore network access first if you are offline. Otherwise, follow the PC or motherboard
  manufacturer's installation order and restart instructions; there is no single order for every PC.
</Callout>
