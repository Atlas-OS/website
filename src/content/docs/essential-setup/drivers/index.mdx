# Drivers guide

Install the drivers your hardware needs. You chose manual installation during setup; this guide walks you through it.

## Why manual installation?

Manual installation gives you:

- **Full control** over driver versions
- **Potentially lower** system resource usage
- **Fewer** potentially unwanted applications

To switch to automatic installation via Windows Update, use the files in the <CodeInline text="2. Drivers" /> directory in the Atlas folder. See <AtlasFolderRestoreLink /> if you can't find it.

<Callout type="info" title="Want to Switch to Automatic?">
  Use the files in the <CodeInline text="2. Drivers" /> directory in the Atlas folder to let
  Windows Update handle driver installation.
</Callout>

## Want to switch to automatic?

Open <CodeInline text="C:\Windows\AtlasDesktop" /><IconArrow /><CodeInline text="2. Drivers" /><IconArrow /><CodeInline text="Drivers from Windows Update" /> and run <CodeInline text="Enable Drivers from Windows Update.reg" />. Restart afterward so Windows can apply the driver policy.

## Which drivers do I need?

Start with the drivers your system needs:

- **Graphics (GPU/iGPU)** – Display output and gaming
- **Audio** – Sound from speakers or headphones
- **Wi-Fi/Network** – Internet connectivity
- **Bluetooth** – Wireless peripherals (only if you use them)
- **Chipset** – System stability and performance

<Callout type="warning" title="Multiple Graphics Cards">
  If you have both integrated and dedicated graphics (e.g., Intel CPU with NVIDIA GPU), install
  drivers for both so you can switch between GPUs.
</Callout>

<Callout type="tip">
  Install in this order: Graphics → Network → Audio → Chipset → Other (Bluetooth, etc.). Display
  and internet work first, then the rest.
</Callout>
