This guide covers installing and configuring NVIDIA, AMD and Intel graphics drivers.
Install them first, because your display and games depend on them.

The Atlas folder's <CodeInline text="2. Drivers" /><IconArrow /><CodeInline text="GPU Drivers" /> folder has shortcuts to NVCleanstall and Display Driver Uninstaller (DDU).

<Callout type="warning" title="Multiple graphics cards">
  If you have integrated and dedicated graphics, you must install both drivers. For example, if you
  have an Intel CPU with integrated graphics and an NVIDIA GPU, install both Intel and NVIDIA
  drivers.
</Callout>

## Quick check

First, check if Windows Update has already installed your graphics drivers:

1. Open **Settings**<IconArrow />**Windows Update**
2. Click **Check for updates**
3. Install any available optional updates

<Callout type="tip">
  Windows Update often installs basic graphics drivers. For better performance, install
  manufacturer-specific drivers afterward.
</Callout>

## NVIDIA drivers

Most users should install the latest NVIDIA driver from NVIDIA. NVCleanstall is an optional advanced tool for users who want to customise which NVIDIA components are installed.

### Installation steps

1. **Download the driver or NVCleanstall**
   - Standard path: use [NVIDIA's driver download page](https://www.nvidia.com/download/find.aspx)
   - Advanced path: use [TechPowerUp NVCleanstall](https://www.techpowerup.com/download/techpowerup-nvcleanstall)
   - If using NVCleanstall, download and open the application, then click **Next**

<Callout type="info" title="Slow download?">
  If the download is unusually slow or stuck, go to [NVIDIA's advanced driver
  search](https://www.nvidia.com/download/find.aspx) and download the latest Game Ready Driver after
  selecting your hardware and operating system. Launch NVCleanstall, choose **Use driver files on
  disk** and locate the previously downloaded driver.
</Callout>

2. **Select components**
   - **For desktops:** Select only **Display Driver**, then click **Next**
   - **For Laptops:** Check **Display Driver** and **Optimus** and click **Next** (More info on [NVIDIA's Website](https://www.nvidia.com/en-us/geforce/technologies/optimus))

3. **Configure installation**
   After the driver is downloaded, tick the following:
   - Disable Installer Telemetry & Advertising
   - Perform a Clean Installation
   - Disable Multiplane Overlay (MPO)
   - Disable Driver Telemetry in **Show Expert Tweaks**
   - Use method compatible with Easy-Anti-Cheat
     - Automatically accept the "driver unsigned" warning

4. Click **Install** and continue with the NVIDIA driver installation as usual.

### NVIDIA Control Panel configuration

Open the NVIDIA Control Panel by right-clicking on the desktop and configure:

<Details summary="3D settings">
- Anisotropic filtering - Off
- Antialiasing - Gamma correction - Off
- Low Latency Mode - On (This setting limits pre-rendered frames to 1)
- Power management mode - Prefer maximum performance
- Shader Cache Size - Unlimited
- Texture filtering - Quality - High performance
- Threaded Optimization - Off (if CPU bottlenecked)
- Vertical sync - Off
</Details>

<Details summary="Display settings">
- Configure your monitor resolution and refresh rate
- Output dynamic range - Full
- Output color depth - Value matching your monitor specification
</Details>

**Optional:** Increase **Digital vibrance** in Display<IconArrow />Adjust desktop color settings for better colour saturation. For an alternative way to adjust digital vibrance, check out [VibranceGUI](https://vibrancegui.com).

### Force P-State 0 (advanced)

<Callout type="danger" title="Warning">
  This will force P-State 0 on your NVIDIA card **AT ALL TIMES**, making it always run at full
  power. Not recommended if you leave your computer idle for long periods, have poor cooling,
  or use a laptop.
</Callout>

<CodeBlock
  title="Run the following command in CMD as administrator:"
  code={`for /f "tokens=*" %a in ('reg query "HKLM\\SYSTEM\\CurrentControlSet\\Control\\Class\\{4d36e968-e325-11ce-bfc1-08002be10318}" /t REG_SZ /s /e /f "NVIDIA" ^| findstr "HK"') do (reg add "%a" /v "DisableDynamicPstate" /t REG_DWORD /d "1" /f)`}
/>

1. Download and extract [NVIDIA Profile Inspector](https://github.com/Orbmu2k/nvidiaProfileInspector).
2. Open the tool. Under **5 - Common**, set **CUDA - Force P2 State** to **OFF**.
3. Select **Apply changes** and restart your PC.

## AMD drivers

Most users should install the latest recommended AMD driver from AMD. RadeonSoftwareSlimmer is an optional advanced tool for users who want to remove AMD driver components before installation.

### Installation steps

1. **Download Drivers**
   - Download the latest WHQL recommended driver from the [AMD Drivers and Support page](https://www.amd.com/en/support)
   - Open **Assets** on the [latest RadeonSoftwareSlimmer release](https://github.com/GSDragoon/RadeonSoftwareSlimmer/releases/latest) and download the ZIP ending in `_net48.zip`.

2. **Configure installation**
   - Open the application and go to the **Pre-Install** tab
   - Select your installer file by clicking **Browse** and then confirm by double-clicking **Next**
   - After the extraction process, untick everything in the **Packages** tab apart from:
     - AMD Display Driver
     - AMD Settings (Required for Radeon Software)
     - These settings might be required for monitor sound:
       - AMD Audio CoProcessor Bus Driver
       - AMD Audio filter driver
       - AMD HDMI Audio driver
       - AMD High-Definition Audio Controller
       - AMD Streaming Audio Filter Driver

3. **Finish the installation**
   - Untick everything in the **Scheduled Tasks** tab
   - Untick everything in the **Display Driver Components**. If you use audio from your monitor, don't remove **High Definition Audio Bus**
   - Click **Modify Installer** and **Run Installer**, then continue with driver setup as usual

### Radeon Software configuration

Open **Start**, search for **AMD Software** and select the app.
In **Gaming** > **Games**, select the game you want to tune.

#### Competitive latency settings

- **VSync.** Turn it off in the game's graphics settings when you prioritise input latency and can tolerate tearing. For OpenGL games, set **Wait for Vertical Refresh** to **Always Off** in the game profile. [AMD's VSync documentation](https://www.amd.com/en/resources/support-articles/faqs/DH-012.html) · [AMD's sync latency comparison](https://www.amd.com/en/products/software/adrenalin/software-enhancedsync.html)
- **Frame generation.** Turn off **AMD Fluid Motion Frames** and any frame generation option in the game when tuning for input latency. Generated frames increase displayed FPS by inserting frames between the ones the game renders. [AMD's frame generation guide](https://www.amd.com/en/products/software/adrenalin/afmf.html)
- **Radeon Chill.** Turn it off in competitive games. It varies FPS based on movement and disables driver-level **Radeon Anti-Lag** when enabled. [AMD's Anti-Lag and Chill guide](https://www.amd.com/en/resources/support-articles/faqs/DH3-033.html)
- **Radeon Anti-Lag.** Use **Anti-Lag 2** in the game's settings if it offers it. Otherwise, try **Radeon Anti-Lag** in the game profile when the GPU is the bottleneck. [AMD Anti-Lag 2](https://gpuopen.com/anti-lag-2/) · [AMD's Anti-Lag and Chill guide](https://www.amd.com/en/resources/support-articles/faqs/DH3-033.html)

If the GPU stays near full load and controls feel sluggish, try an in-game FPS limit your PC can hold with some GPU headroom.
Compare the same scene with and without the limit.
Use the game's input latency reading if it provides one.

<Details summary="Increase rendered FPS">

If the GPU limits your FPS, lower the game's render scale or use its upscaler before changing driver settings.
Open **Advanced** in the game profile.

- **Texture Filtering Quality.** Try **Performance** if you can trade texture quality for more FPS.
- **Tessellation Mode.** To reduce geometry detail, choose **Override Application Settings** and lower **Maximum Tessellation Level**. Test the change in one game first.

See [AMD's graphics settings guide](https://www.amd.com/en/resources/support-articles/faqs/DH3-012.html) for per-game profiles and advanced controls.

</Details>

<Details summary="Display settings">

In Windows, open **Settings** > **System** > **Display** and select your monitor.
Open **Advanced display** and pick the highest refresh rate available at your chosen resolution. [Microsoft's refresh rate guide](https://support.microsoft.com/en-gb/windows/hardware/display-graphics/change-the-refresh-rate-on-your-monitor-in-windows)

In AMD Software, search for **Display Settings** to check FreeSync and GPU Scaling for your monitor.

- **AMD FreeSync.** For smoother motion on a compatible display, try FreeSync with an in-game FPS limit just below the monitor's maximum refresh rate. Compare **On** and **Off** in the game's profile if responsiveness varies. [AMD's FreeSync guidance](https://www.amd.com/en/products/graphics/technologies/freesync.html)
- **GPU Scaling.** Leave it off at native resolution. Enable it if you need to stretch a lower-resolution image or preserve its aspect ratio. [AMD's scaling guide](https://www.amd.com/en/resources/support-articles/faqs/DH3-019.html)

</Details>

<Details summary="Privacy, overlays and hotkeys">

Search for **Preferences Settings** in AMD Software.

- **AMD User Experience Program.** If you're enrolled, select **Unsubscribe** to stop sharing usage data through the programme. [AMD's privacy information](https://www.amd.com/en/legal/privacy/user-experience-program.html)
- **Game Adjustment Tracking and Notifications.** Turn it off to stop AMD Software using game performance and settings to make recommendations.
- **In-Game Overlay.** Turn it off if you don't use the AMD overlay. [AMD's preferences guide](https://www.amd.com/en/resources/support-articles/faqs/DH3-001.html)

Use **Hotkey Settings** to clear shortcuts you don't use or change ones that conflict with a game.
To stop background recording, open **Record & Stream Settings** and turn off **Instant Replay** and **Record Desktop**. [AMD's recording settings](https://www.amd.com/en/resources/support-articles/faqs/DH3-023.html)

</Details>

<Details summary="Optional AMD services">

Test the driver and display first, then change one service at a time in RadeonSoftwareSlimmer.
The **AMD Crash Defender Service** adds crash diagnostics. Disable it only if you're willing to give up those diagnostics.
Keep **AMD External Events Utility** enabled if you use FreeSync. [RadeonSoftwareSlimmer's service reference](https://github.com/GSDragoon/RadeonSoftwareSlimmer/wiki/System-Services-and-Drivers)

1. Open **Post Install** in RadeonSoftwareSlimmer and select **Load/Refresh Radeon Software Installed Components**.
2. Open **System Services**, clear **Enabled** for **AMD Crash Defender Service** if it's listed, and select **Apply Changes**.
3. Restart and check that games and display features still work as expected.

To restore the service, select **Enabled**, select **Apply Changes** and restart.

</Details>

### Disable Multi-Plane Overlay (MPO)

Disabling Multi-plane Overlay (MPO) can fix flickering or stuttering in desktop apps during hardware-accelerated video playback in browsers.

## Troubleshooting

### Driver installation fails

- **Disable antivirus temporarily:** Some antivirus blocks driver installations
- **Run installer as administrator:** Right-click installer<IconArrow />**Run as administrator**
- **Clean previous drivers:** Use [Display Driver Uninstaller (DDU)](https://www.wagnardsoft.com/display-driver-uninstaller-ddu) for NVIDIA or AMD

### Games not performing well

- **Update to latest drivers:** Newer drivers often include game optimisations
- **Check GPU power settings:** Set GPU to maximum performance
- **Verify GPU is being used:** Some systems use integrated graphics instead of dedicated GPU

### Multiple GPUs

If you have both integrated and dedicated graphics:

1. Install drivers for both GPUs
2. Configure in BIOS/UEFI to use dedicated GPU for gaming
3. Set preferred GPU in Windows graphics settings

## Best practices

- **Download from official sources only:** Avoid third-party driver sites
- **Keep drivers updated:** Check monthly or when you have issues
- **Prefer manufacturer sites if unsure:** NVIDIA, AMD, Intel, and your device manufacturer provide the safest baseline installers
- **Treat slimming tools as optional:** NVCleanstall and RadeonSoftwareSlimmer are for advanced users who understand the support trade-offs
- **Avoid beta drivers:** use stable releases unless you need a specific feature
