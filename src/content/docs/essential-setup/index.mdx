# Essential setup

After installing AtlasOS, install your drivers first. Apply the optional hardware optimizations afterward.

## Follow your driver method

Follow the option you selected during installation.

### If you chose Windows Update (automatic)

Windows Update installs drivers automatically. Verify everything is up to date:

1. Open **Settings**<IconArrow />**Windows Update**
2. Click **Check for updates**
3. Install all available updates, including optional updates (especially driver updates)
4. Restart if prompted, then check for updates again until no more are available

<Callout type="tip">
  If internet and display work, Windows Update likely installed your drivers. Skip the drivers
  section and go to hardware optimization (optional).
</Callout>

**Next:** Continue to [hardware optimization](/docs/essential-setup/hardware/) or skip it.

### If you chose manual installation

Install drivers yourself for full control over versions.

**Next:** [Install your drivers](/docs/essential-setup/drivers/), then continue to hardware optimization or skip it.
