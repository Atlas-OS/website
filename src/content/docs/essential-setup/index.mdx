This section helps you finish setting up your PC after installing Atlas.
Install your drivers first, then apply the optional hardware optimisations.

## Follow your driver choice

Atlas Manager gets drivers through Windows Update, unless you chose **Install drivers myself** on the **Get ready** page or when you created an Atlas ISO.
Follow the steps for your choice.

### If you chose Get drivers through Windows Update

Windows Update installs drivers for your hardware. Check that everything is up to date:

1. Open **Settings**<IconArrow />**Windows Update**
2. Select **Check for updates**
3. Install the available updates, including optional driver updates
4. Restart if prompted, then check for updates again until none are left

<Callout type="tip">
  If your internet connection and display work, Windows Update has probably installed your drivers.
  You can skip the drivers guide and go to hardware optimisation, which is optional.
</Callout>

**Next:** Continue to [hardware optimisation](/docs/essential-setup/hardware/), or skip it.

### If you chose Install drivers myself

Windows Update doesn't install drivers, so you choose each driver and its version yourself.
Drivers that were already installed are kept.

**Next:** [Install your drivers](/docs/essential-setup/drivers/), then continue to hardware optimisation or skip it.
