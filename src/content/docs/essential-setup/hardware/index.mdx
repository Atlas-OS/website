# Hardware optimization

These optional optimizations can improve performance, especially for gaming. Hardware optimization is optional but recommended.

<Callout type="info" title="Update BIOS First">
  Update BIOS before enabling XMP/DOCP or Resizable BAR. Enabling them first can cause settings to
  revert after the update.
</Callout>

## Recommended order

Follow this order:

1. **[Update BIOS](/docs/essential-setup/hardware/bios-update/)** – First, to avoid settings reverting
2. **[Enable XMP/DOCP](/docs/essential-setup/hardware/memory/)** – Unlock RAM speed
3. **[Enable Resizable BAR](/docs/essential-setup/hardware/gpu/)** – Improve GPU performance

## What these features do

### XMP/DOCP (Memory Overclocking)

- Lets RAM run at its advertised speed
- Can improve performance, especially in games
- Intel uses XMP, AMD uses DOCP

### Resizable BAR (GPU Enhancement)

- Improves CPU–GPU communication
- Can improve FPS by up to 15% in some games
- Requires NVIDIA GeForce 30 series or AMD Radeon RX 6000 Series or newer

### BIOS updates

- Adds hardware support
- Security and bug fixes
- More configuration options
- Better performance and stability
