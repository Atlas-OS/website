# Antivirus

<Callout type="tip" title="We recommend Windows Defender">
  Windows Defender is free, updated, and integrated into Windows. Consider the options below if you
  want something more advanced.
</Callout>

Reliable antivirus options: on-demand and real-time solutions.

## Real-time scanners

These apps run continuously to protect against malware.

### Windows Defender (Highly Recommended)

Lightweight, consistently updated malware definitions and native protection inside Windows. It is enabled by default on AtlasOS.

### Bitdefender Antivirus Free Edition

Offers lightweight yet effective protection. Use the official Bitdefender product page if the direct installer link changes.

[Download Bitdefender](https://download.bitdefender.com/windows/installer/en-us/bitdefender_avfree.exe)

## On-demand scanners

These tools scan and remove threats on demand. They don't run continuously.

<Callout type="info" title="Kaspersky availability">
  Kaspersky is not available in the United States.
</Callout>

### Kaspersky Virus Removal Tool (Recommended)

A powerful tool for detecting and eliminating various types of malware.

[Download Kaspersky Virus Removal Tool](https://www.kaspersky.com/downloads/free-virus-removal-tool)

### HitmanPro

Effective in finding and removing new and complex malware.

[Download HitmanPro](https://www.hitmanpro.com/)

### Malwarebytes

Effective at detecting and removing malware.

[Download Malwarebytes](https://www.malwarebytes.com/)

### ESET Online Scanner

A one-time tool for thorough malware removal.

[Download ESET Online Scanner](https://www.eset.com/int/home/online-scanner/)

### AdwCleaner

Specializes in removing adware and PUPs.

[Download AdwCleaner](https://downloads.malwarebytes.com/file/adwcleaner)
