This page lists antivirus apps that work with AtlasOS: real-time scanners, which protect you all the time, and on-demand scanners, which you run when you need them.

<Callout type="tip" title="Start with Microsoft Defender">
  Microsoft Defender is free, regularly updated and built into Windows. Consider the options below
  if you want something different.
</Callout>

## Real-time scanners

These apps run all the time to protect against malware.

<Callout type="warning" title="Install other antivirus apps after Atlas">
  Antivirus apps other than Microsoft Defender can block the Atlas installation, so Atlas Manager
  asks you to uninstall them first. Install a real-time scanner after Atlas is installed.
</Callout>

### Microsoft Defender (recommended)

Microsoft Defender is the antivirus built into Windows, with regularly updated malware definitions.
When you install Atlas, **Keep Microsoft Defender (recommended)** is the default choice.
See [Defender](/docs/atlas-configuration/security/#defender) for what each choice means and how to change it later.

### Bitdefender Antivirus Free Edition

Bitdefender's free edition offers lightweight protection.
Use the official Bitdefender product page if the direct installer link changes.

[Download Bitdefender](https://download.bitdefender.com/windows/installer/en-us/bitdefender_avfree.exe)

## On-demand scanners

These tools scan and remove threats on demand. They don't run continuously.

<Callout type="info" title="Kaspersky availability">
  Kaspersky isn't available in the United States.
</Callout>

### Kaspersky Virus Removal Tool (recommended)

A free tool for finding and removing many types of malware.

[Download Kaspersky Virus Removal Tool](https://www.kaspersky.com/downloads/free-virus-removal-tool)

### HitmanPro

Finds and removes new and complex malware.

[Download HitmanPro](https://www.hitmanpro.com/)

### Malwarebytes

Detects and removes malware.

[Download Malwarebytes](https://www.malwarebytes.com/)

### ESET Online Scanner

A one-time scanner for thorough malware removal.

[Download ESET Online Scanner](https://www.eset.com/int/home/online-scanner/)

### AdwCleaner

Removes adware and potentially unwanted programs.

[Download AdwCleaner](https://downloads.malwarebytes.com/file/adwcleaner)
