**Notes:**

- [Chrome](https://tosdr.org/en/service/217) and [Edge](https://tosdr.org/en/service/244) collect significant telemetry and user data.
- [Helium](https://helium.computer/) is an open-source Chromium browser with ad and tracker blocking enabled by default. It is currently in beta and does not include browser sync, a built-in password manager, or Widevine DRM support for some streaming services.
- LibreWolf's privacy protections may require turning off protections for specific websites.
- See [privacytests.org](https://privacytests.org/) for tracking prevention comparisons.
