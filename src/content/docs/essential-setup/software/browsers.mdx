This page compares browsers you can use on AtlasOS by privacy, ease of use and features.

When you install Atlas, the **Your choices** page offers **Remove Microsoft Edge** and **Install a browser**.
Atlas can install Brave, LibreWolf, Firefox or Chrome, and doesn't change the browser's settings.

Before you remove Edge, back up any bookmarks or passwords you want to keep.
Removing Edge deletes its bookmarks, history and saved passwords from that PC.
To install or remove Edge later, run <CodeInline text="Install or Remove Edge.cmd" /> in the Atlas folder's <CodeInline text="1. Software" /> folder.

**Notes:**

- [Chrome](https://tosdr.org/en/service/217) and [Edge](https://tosdr.org/en/service/244) collect significant telemetry and user data.
- [Helium](https://helium.computer/) is an open-source Chromium browser with ad and tracker blocking enabled by default. Check its website for the features it supports, such as browser sync, a built-in password manager and the Widevine DRM some streaming services need.
- LibreWolf's privacy protections can break some websites, so you may need to turn them off for those sites.
- See [privacytests.org](https://privacytests.org/) for tracking prevention comparisons.
