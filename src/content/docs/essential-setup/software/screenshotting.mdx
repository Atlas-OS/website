This page lists tools for taking screenshots and screen recordings on AtlasOS.

## Snipping Tool

Snipping Tool comes with Windows.

<Callout type="info" title="Removed during Atlas setup?">
  If you chose **Remove Snipping Tool** when you installed Atlas, Atlas can't put it back, but you can
  install it again from the Microsoft Store or with the command below.
</Callout>

<CodeBlock
  title="Install with winget:"
  code="winget install -e --id 9MZ95KL8MR0L"
/>

[Download Snipping Tool](https://apps.microsoft.com/store/detail/9MZ95KL8MR0L) (Microsoft Store)

## ShareX

ShareX captures screenshots and screen recordings, with editing tools. It suits most people.

<CodeBlock
  title="Install with winget:"
  code="winget install -e --id ShareX.ShareX"
/>

[Download ShareX](https://apps.microsoft.com/store/detail/9NBLGGH4Z1SP) (Microsoft Store)

## Lightshot

Lightshot is a lightweight proprietary tool for capturing and editing screenshots. Choose ShareX for more features or Lightshot for a simpler interface.

<CodeBlock
  title="Install with winget:"
  code="winget install -e --id Skillbrains.Lightshot"
/>

[Download Lightshot](https://app.prntscr.com/en/index.html)

## Flameshot

Flameshot is simple open-source screenshot software with capture, upload and annotation tools.

<CodeBlock
  title="Install with winget:"
  code="winget install -e --id Flameshot.Flameshot"
/>

[Download Flameshot](https://flameshot.org/#download)
