This page explains how to install software on AtlasOS and lists apps we recommend.
Install software with WinGet, from the Atlas folder, or from the publisher's official website.

## What is WinGet?

WinGet is Microsoft's Windows Package Manager.
Windows installs it as part of App Installer, and the community maintains its package repository.

Atlas's software tools use WinGet.
If one says WinGet is missing or out of date, update or install App Installer from the Microsoft Store, then try again.

## The 1. Software folder

The Atlas folder's <CodeInline text="1. Software" /> folder has these tools:

| File | What it does |
| --- | --- |
| <CodeInline text="Install Software.cmd" /> | Opens Atlas's software picker, which installs the apps you select through WinGet. |
| <CodeInline text="Install or Remove Edge.cmd" /> | Installs Microsoft Edge, or removes it. |
| <CodeInline text="Remove Python Store Prompt.cmd" /> | Opens App execution aliases, so you can turn off only the App Installer prompts that offer Python from the Microsoft Store. Python you've installed is kept. |

## Install software with WinGet

To install a package directly, run:

<CodeBlock
  title="Install with winget:"
  code="winget install -e --id VideoLAN.VLC"
/>

Replace <CodeInline text="VideoLAN.VLC" /> with the package ID from [winstall.app](https://winstall.app/).
