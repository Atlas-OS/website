# Software

Install software with WinGet or download it directly from the publisher's official site.

Atlas software scripts use **WinGet** (Windows Package Manager). Windows 11 normally installs it through App Installer.

## What is WinGet?

WinGet is Microsoft's Windows package manager. The Microsoft Store installs it as part of App Installer, and the community maintains its package repository.

If an Atlas script says WinGet is missing or outdated, update App Installer from the Microsoft Store or GitHub before using WinGet-based installers.

## Installing software with WinGet

Open <CodeInline text="1. Software" /> in the Atlas folder and run <CodeInline text="Install Software.cmd" />. To install a package directly, run:

<CodeBlock
  title="Install with winget:"
  code="winget install -e --id VideoLAN.VLC"
/>

Replace <CodeInline text="VideoLAN.VLC" /> with the package ID from [winstall.app](https://winstall.app/).
