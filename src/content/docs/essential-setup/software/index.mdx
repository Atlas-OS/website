# Software

Use a package manager to install software. You can also install executables directly from official sources.

We use **WinGet** (Windows Package Manager), which comes pre-installed on Windows.

## What is WinGet?

WinGet is Microsoft's Windows package manager, installed via the App Installer package on the Microsoft Store. The community runs the repository. It works like apt-get on Linux and Homebrew on macOS.

## Installing software with WinGet

Go to the <CodeInline text="1. Software" /> folder in the Atlas folder and run <CodeInline text="Install Software.cmd" />. Or install manually:

<CodeBlock
  title="Install with winget:"
  code="winget install -e --id VideoLAN.VLC"
/>

Replace <CodeInline text="VideoLAN.VLC" /> with the package ID from [winstall.app](https://winstall.app/).
