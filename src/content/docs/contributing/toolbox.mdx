# Contributing to the Atlas Toolbox

Use this guide to modify, build, and test Atlas Toolbox. Read the [contribution guide](/docs/contributing/) first.

Clone the <CodeInline text="Atlas-OS/atlas-toolbox" /> repository before you continue.

## What Atlas Toolbox uses internally

The Atlas Toolbox uses:

1. [C# (.NET 8.0)](https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/)
2. [XAML](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/xaml/?view=netdesktop-9.0)

Development tools and resources:

- [Visual Studio Community 2022](https://visualstudio.microsoft.com/vs/)
  - The Toolbox repo contains the default NuGet packages required.
- [.NET 8 Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) - Required if your development environment does not already include it.
- [Windows App SDK 1.6](https://learn.microsoft.com/en-us/windows/apps/windows-app-sdk/downloads) - Required if your development environment does not already include it.

UI demos for the Toolbox:

- [WinUI 3 Gallery](https://apps.microsoft.com/detail/9p3jfpwwdzrc)
- [Windows Community Toolkit Gallery](https://apps.microsoft.com/detail/9nblggh4tlcq)
