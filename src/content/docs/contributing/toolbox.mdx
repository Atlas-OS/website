# Contributing to the Atlas Toolbox

This guide covers modifying, testing, and building Atlas Toolbox. Read the [Contribution Guidelines](/docs/contributing/) first.

This assumes you've already cloned the <CodeInline text="Atlas-OS/atlas-toolbox" /> repository.

## What Atlas Toolbox uses internally

The Atlas Toolbox uses:

1. [C# (.NET 8.0)](https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/)
2. [XAML](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/xaml/?view=netdesktop-9.0)

Development tools and resources:

- [Visual Studio Community 2022](https://visualstudio.microsoft.com/vs/)
  - The Toolbox repo contains the default NuGet packages required.
- [.Net 8 Runtime](https://download.visualstudio.microsoft.com/download/pr/fc8c9dea-8180-4dad-bf1b-5f229cf47477/c3f0536639ab40f1470b6bad5e1b95b8/windowsdesktop-runtime-8.0.13-win-x64.exe) - Included in AtlasOS v0.5.0+
- [Windows App SDK 1.6](https://download.microsoft.com/download/7a3a6a44-b07e-4ca5-8b63-2de185769dbc/WindowsAppRuntimeInstall-x64.exe) - Included in AtlasOS v0.5.0+

UI demos for the Toolbox:

- [WinUI 3 Gallery](https://apps.microsoft.com/detail/9p3jfpwwdzrc)
- [Windows Community Toolkit Gallery](https://apps.microsoft.com/detail/9nblggh4tlcq)
