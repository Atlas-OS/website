# Contribution guide

This guide explains how to contribute to AtlasOS. We welcome all contributions.

## Our contribution platform

Atlas uses [GitHub](https://github.com/Atlas-OS) for everything. This documentation doesn't cover GitHub or Git; if you're new to them, see the [GitHub quick-start guide](https://docs.github.com/get-started/quickstart) first.

Read the [Code of Conduct](https://github.com/Atlas-OS/.github/blob/main/profile/CODE_OF_CONDUCT.md) before contributing.

## How to make changes

<Callout type="tip" title="Unsure if people will like your change?">
  Propose it in [Discord](https://discord.com/invite/atlasos) or [GitHub
  issues](https://github.com/Atlas-OS/Atlas/issues) first. Mistakes are fine—reviewers will give
  feedback in pull requests. You don't need to get everything right on the first try.
</Callout>

Follow these steps to contribute:

1. **Fork or branch** – Create a fork (external contributors) or branch (team members)
2. **Make your changes** – Implement your improvements or fixes
3. **Submit a pull request** – Open a PR against the primary branch
4. **Wait for reviews** – At least two reviews (team members need one)
5. **Merge** – Once approved, your PR is squash-merged into one commit

<Callout type="info">
  Team members may skip pull requests for uncontroversial, well-tested changes that don't require
  review.
</Callout>

## Formatting

Before submitting a pull request:

- Match the repository's formatting
- Check grammar and fix mistakes
  - For YAML changes, run a linter to verify validity

## Commit signature verification

Set up [commit signature verification](https://docs.github.com/en/authentication/managing-commit-signature-verification) so your commits show as **Verified**. See this [guide for verified commits](https://gist.github.com/Beneboe/3183a8a9eb53439dbee07c90b344c77e#file-how-to-setup-verified-commits-md).
