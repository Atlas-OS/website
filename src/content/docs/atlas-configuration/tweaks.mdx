Personalize File Explorer, context menus, and the lock screen. These are optional preferences, not extra steps needed to finish installing Atlas.

The defaults below describe a fresh Atlas 0.6 installation. Upgrades can preserve recognized choices, and a `(default)` filename does not tell you which setting is currently active. See [configuration basics](/docs/atlas-configuration/settings/#before-you-start).

Open <CodeInline text="4. Interface Tweaks" /> in the Atlas folder on your Desktop. Delivery Optimization is under <CodeInline text="3. General Configuration" />. If the Atlas folder is missing, follow{' '}<AtlasFolderRestoreLink />.

<Callout type="info" title="Restart required">
  Follow the script's prompts. Some changes need Explorer to restart or require you to sign out;
  a full PC restart is not always necessary. Save your work first.
</Callout>

## Delivery optimization

**When to use:** Enable if you want faster Windows Updates by sharing data with other Windows devices on your local network.

Delivery Optimization can download update content from other PCs. Atlas's disable preset turns off peer-to-peer sharing; Windows can still download updates from Microsoft. See Microsoft's [download-mode reference](https://learn.microsoft.com/en-us/windows/win32/delivery_optimization/downloadmode).

To enable Delivery Optimization, run the <CodeInline text="Enable Delivery Optimization.cmd" /> script in <CodeInline text="3. General Configuration" /><IconArrow /><CodeInline text="Delivery Optimization" /> and restart.

<Callout type="info">
  The enable script removes Atlas's download-mode policy. Review Delivery Optimization in Windows
  Update's advanced options afterwards to choose whether sharing is allowed and with which PCs.
</Callout>

## File Explorer customization

Personalize how File Explorer looks and behaves with these options.

### Compact view

**When to use:** Disable if you prefer the default Windows 11 spacing with more padding.

Windows 11 introduced larger padding in File Explorer. AtlasOS uses compact view by default to show more content in the same space.

**To revert to default spacing:**

- Option 1: In File Explorer, go to **View**<IconArrow />**Compact View** to toggle it
- Option 2: Run the <CodeInline text="Disable Compact View.cmd" /> script in <CodeInline text="File Explorer Customization" /><IconArrow /><CodeInline text="Compact View" />

### Gallery

**When to use:** Enable if you want Windows 11's gallery feature for viewing images in File Explorer.

The Gallery feature provides an image viewing experience in File Explorer. AtlasOS disables it by default.

To enable Gallery, run the <CodeInline text="Enable Gallery.cmd" /> script in <CodeInline text="File Explorer Customization" /><IconArrow /><CodeInline text="Gallery" /> and restart.

### Quick Access

**When to use:** Remove if you don't use pinned folders and prefer a cleaner File Explorer sidebar.

Quick Access shows your pinned folders at the top of File Explorer. It's enabled by default.

To remove Quick Access, run the <CodeInline text="Remove Quick Access.cmd" /> script in <CodeInline text="File Explorer Customization" /><IconArrow /><CodeInline text="Quick Access" /> and restart.

### Removable drives in sidebar

**When to use:** Enable if you want to see USB drives and other removable devices in the File Explorer sidebar.

By default, removable drives may not appear in the File Explorer sidebar. Enable this to make them visible.

To enable, run the <CodeInline text="Enable Removable Drives in Sidebar.cmd" /> script in <CodeInline text="File Explorer Customization" /><IconArrow /><CodeInline text="Removable Drives in Sidebar" /> and restart.

## Lock screen

**When to use:** Disable if you don't want a lock screen when waking your system.

AtlasOS enables the lock screen by default. Disable it to go directly to the sign-in screen.

To hide it, run <CodeInline text="Hide Lock Screen.cmd" /> in <CodeInline text="Lock Screen" />. To restore it, run <CodeInline text="Show Lock Screen (default).cmd" />.

<Callout type="info">
  Disabling the lock screen skips the background image and time display, going directly to sign-in.
</Callout>

## Run with priority in context menu

**When to use:** Enable if you want to control application priority from the right-click menu.

This tweak adds an option to set application priority (high, normal, low, etc.) directly from the context menu when right-clicking executable files.

To enable, run the <CodeInline text="Add Run With Priority In Context Menu.cmd" /> script in <CodeInline text="Context Menus" /><IconArrow /><CodeInline text="Run With Priority" /> and restart.

<Callout type="tip">
  Useful for running specific applications with higher or lower priority to manage system resource
  allocation.
</Callout>

## Send to context menu

**When to use:** Use if you want to clean up the "Send to" menu by removing unnecessary items.

Reduce clutter in the "Send to" context menu by removing default items you don't use.

To clean up the menu, run the <CodeInline text="Debloat Send To Context Menu.cmd" /> script in <CodeInline text="Context Menus" /><IconArrow /><CodeInline text="Send To" />.

## Shortcut icon

**When to use:** Change if you prefer classic shortcut arrows or want a different visual style.

Customize how shortcut icons appear. Options include Windows default, classic style, or no indicator at all.

**Options:**

- **Windows Default:** Current default style
- **Classic:** Traditional shortcut arrow indicator
- **None:** No visual indicator (not recommended)

To change to classic style, run the <CodeInline text="Classic.cmd" /> script in <CodeInline text="Shortcut Icon" />.

<Callout type="warning" title="Security Risk">
  Disabling shortcut icons entirely ("None" option) is a security risk because you won't be able to
  visually distinguish shortcuts from regular files. This could make you vulnerable to malicious
  files disguised as shortcuts.
</Callout>

## Shortcut text

**When to use:** Enable if you want Windows to add " - Shortcut" to the names of newly created shortcuts.

Atlas removes this suffix by default. This setting does not hide icon labels or rename existing shortcuts.

To enable shortcut text, run the <CodeInline text="Restore Shortcut Text.cmd" /> script in <CodeInline text="Shortcut Text" /> and restart.

## Windows 11 context menu

**When to use:** Enable if you prefer Windows 11's modern context menu over the classic right-click menu.

AtlasOS uses the classic context menu by default for faster access to options. Switch to Windows 11's modern context menu if you prefer its appearance.

**Default:** Classic context menu

**To use Windows 11 context menu:**

1. Run the <CodeInline text="New Context Menu.cmd" /> script in <CodeInline text="Context Menus" /><IconArrow /><CodeInline text="Windows 11" />
2. Restart your system

<Callout type="tip">
  The modern context menu has a cleaner look but requires an extra click ("Show more options") to
  access some features. The classic menu shows everything immediately.
</Callout>

## Explorer Patcher

**When to use:** Explore if you want additional shell customization beyond the Atlas folder's settings.

ExplorerPatcher is a third-party Windows shell customization tool. Its supported features depend on the Windows build and tool version.

The Atlas folder includes a website shortcut under **4. Interface Tweaks → Start Menu**. Check [ExplorerPatcher's compatibility notes and releases](https://github.com/valinet/ExplorerPatcher) before installing it on Windows 11 25H2.

<Callout type="info">
  Explorer Patcher is a third-party tool that requires installation. It's included as a convenient
  shortcut for users who want to customize their Windows interface further.
</Callout>

Explore the <CodeInline text="4. Interface Tweaks" /> folder to discover and try them.
