## Before you start

These instructions describe Atlas 0.6. Your current settings also depend on your installation choices and changes made afterwards. A filename containing `(default)` identifies a supplied preset; it does not prove that preset is active on your PC.

Change one setting at a time, follow the script's restart or sign-out prompt, and check the result before changing anything else. During an upgrade, Atlas reapplies recognized recorded choices; it cannot recover every custom registry edit. See [what carries over](/docs/upgrade/requirements/).

For more configuration options, check:

- [Advanced Configuration](/docs/atlas-configuration/advanced/) - Advanced system options
- [Optional Tweaks](/docs/atlas-configuration/tweaks/) - Interface personalization
- [Windows Settings](/docs/atlas-configuration/windows/) - Quick shortcuts to Windows configuration

## Background apps

**When to use:** Enable if an app needs background access to work correctly.

Atlas restricts background access for Windows apps on a fresh installation. This setting does not stop every desktop application or startup program from running in the background.

To enable background apps, run the <CodeInline text="Enable Background Apps.cmd" /> script in <CodeInline text="3. General Configuration" /><IconArrow /><CodeInline text="Background Apps" /> and restart your system.

## Bluetooth

**When to use:** Disable only if you do not use Bluetooth devices like headphones, speakers, or game controllers.

AtlasOS enables Bluetooth by default. Disable it if you do not use Bluetooth devices.

1. Run <CodeInline text="Disable Bluetooth.cmd" /> or <CodeInline text="Enable Bluetooth (default).cmd" /> in <CodeInline text="6. Advanced Configuration" /><IconArrow /><CodeInline text="Services" /><IconArrow /><CodeInline text="Bluetooth" />
2. Restart your system
3. If Bluetooth still does not work, install its driver from your motherboard or device manufacturer's support site

<Callout type="tip">
  Need help finding Bluetooth drivers? Check [our drivers
  guide](/docs/essential-setup/drivers/other/) for instructions.
</Callout>

## Driver updates

**When to use:** Switch between automatic and manual driver installation based on your preference.

During installation, you choose automatic driver installation through Windows Update or manual installation. Use these files to switch methods later.

To switch methods:

1. Open the <CodeInline text="Drivers from Windows Update" /> folder (in <CodeInline text="2. Drivers" />)
2. Run the appropriate script or registry file for your desired method
3. Restart your system

**Automatic:** Windows Update installs available drivers. Some devices still need a manufacturer package; see the [drivers guide](/docs/essential-setup/drivers/).
**Manual:** You install drivers yourself for full control over versions.

## Automatic Windows Updates

**When to use:** Enable if you want Windows to install system updates automatically. Disable if you prefer update notifications and manual control.

During installation, you choose how Atlas handles automatic Windows updates. To change that choice, open <CodeInline text="3. General Configuration" /><IconArrow /><CodeInline text="Automatic Updates" />.

- <CodeInline text="Disable Automatic Updates (default).cmd" /> restores the Atlas default.
- <CodeInline text="Enable Automatic Updates.cmd" /> lets Windows install updates automatically.
- The separate <CodeInline text="Pause Updates" /> and <CodeInline text="Update Notifications" /> folders under <CodeInline text="3. General Configuration" /> provide related controls.

## FSO and Game Bar

**When to use:** Enable Game Bar if you want to record gameplay, take screenshots, or monitor performance. Disable FSO if you prefer fullscreen exclusive mode.

Game Bar is a Windows feature for screen recording, screenshots, and performance monitoring. It relies on Fullscreen Optimizations (FSO), which AtlasOS enables by default.

### Restore the default

FSO and Game Bar support are enabled by default. To restore the default:

1. Run the <CodeInline text="Enable FSO and Game Bar Support (default).cmd" /> script in <CodeInline text="3. General Configuration" /><IconArrow /><CodeInline text="FSO and Game Bar" />
2. The script also installs Game Bar from the Microsoft Store if needed

### Disable FSO (Fullscreen Exclusive Mode)

If you prefer fullscreen exclusive mode (better for some games with frame limiting), disable FSO:

1. Run the <CodeInline text="Disable FSO and Game Bar Support.cmd" /> script in <CodeInline text="3. General Configuration" /><IconArrow /><CodeInline text="FSO and Game Bar" />
2. This fixes compatibility with the "Disable fullscreen optimizations" option in game compatibility settings

<Callout type="info">
  Learn more about [Fullscreen
  Optimizations](https://devblogs.microsoft.com/directx/demystifying-full-screen-optimizations/) and
  [Fullscreen Exclusive](https://wiki.special-k.info/en/SwapChain) modes.
</Callout>

## HAGS (Hardware-Accelerated GPU Scheduling)

**When to use:** Check this setting when an application requires it, or compare its effect on your own games.

HAGS moves some GPU scheduling work to the GPU. Availability depends on your hardware and driver, and enabling it does not guarantee higher performance.

To test HAGS:

1. Install the appropriate graphics driver
2. Open Windows Settings<IconArrow />**System**<IconArrow />**Display**<IconArrow />**Graphics** and look for the hardware-accelerated GPU scheduling option under the default graphics settings
3. Restart your system
4. Test your applications to see if performance improves

<Callout type="info">
  HAGS is controlled through Windows Settings, not the Atlas folder. The impact varies by system and
  application, so testing is recommended.
</Callout>

## Lanman workstation (SMB)

**When to use:** Keep enabled if you access network shares, mapped drives, or network printers.

Lanman Workstation provides SMB client support for connecting to other computers' shares. This is separate from sharing folders from your own PC. Disabling it can break those connections and software that depends on them.

To disable SMB, run the <CodeInline text="Disable Lanman Workstation.cmd" /> script in <CodeInline text="6. Advanced Configuration" /><IconArrow /><CodeInline text="Services" /><IconArrow /><CodeInline text="Lanman Workstation (SMB)" /> and restart.

## Network discovery

**When to use:** Disable if you don't need to see or share with other computers on your network.

Network discovery lets computers find one another on a local network. Its services, Windows network profile, firewall rules, and File Explorer visibility are separate controls. Enabling the services alone does not configure all of them.

### Disable network discovery

To disable network discovery, run the <CodeInline text="Disable Network Discovery Services.cmd" /> script in <CodeInline text="6. Advanced Configuration" /><IconArrow /><CodeInline text="Services" /><IconArrow /><CodeInline text="Network Discovery" /> and restart.

### Enable file sharing

Atlas disables file sharing on a fresh installation. To share files with other Windows devices on your network:

1. Run the <CodeInline text="Enable File Sharing.cmd" /> script in <CodeInline text="3. General Configuration" /><IconArrow /><CodeInline text="File Sharing" />
2. Review the prompts for switching active networks to **Private**, enabling sharing rules, and restoring the sharing context menu. Only use Private for networks you trust.
3. Restart when prompted, then choose the specific folders and users to share with in Windows. Enabling sharing support does not share every folder automatically.

### Network navigation pane

Control whether **Network** appears in File Explorer with <CodeInline text="Enable Network Navigation Pane.cmd" /> or <CodeInline text="Disable Network Navigation Pane (default).cmd" /> in <CodeInline text="3. General Configuration" /><IconArrow /><CodeInline text="File Sharing" /><IconArrow /><CodeInline text="Network Navigation Pane" />. Showing this item does not itself enable sharing.

## Power settings

Control power-related behavior that affects performance, responsiveness, and power consumption.

### CPU idle

Keep CPU idle enabled for normal use, especially on laptops. Disabling it prevents processor idle power saving and can increase heat and power consumption; a performance benefit is not guaranteed.

The <CodeInline text="CPU Idle" /> folder under <CodeInline text="3. General Configuration" /> contains <CodeInline text="Disable Idle.cmd" /> and <CodeInline text="Enable Idle (default).cmd" />. Atlas rejects disabling idle on systems with Hyper-Threading or SMT enabled.

### Hibernation

**When to use:** Enable if you want your system to save its state to disk when shutting down (useful for quick resume).

Hibernation saves your session to disk so you can resume it later. Atlas 0.6 disables it when you select **Disable Hibernation** during installation. Leaving that choice unchecked does not force hibernation on if it was already disabled.

To enable hibernation, run the <CodeInline text="Enable Hibernation.cmd" /> script in <CodeInline text="3. General Configuration" /><IconArrow /><CodeInline text="Hibernation" />.

### Power saving

**When to use:** Adjust based on your priority, performance vs. power efficiency.

The **Maximum Performance (Disable Power Saving)** installation choice applies Atlas's power policy. Keeping power saving uses the Balanced plan during installation. Consider battery life, heat, and your workload before changing this choice.

To modify power saving settings, use the scripts in <CodeInline text="3. General Configuration" /><IconArrow /><CodeInline text="Power-saving" />.

### Timer resolution

Atlas leaves its forced timer-resolution task disabled by default. Enable it only to investigate a specific timing problem and compare the result in the affected application; it can increase power consumption.

Use <CodeInline text="Enable timer resolution.cmd" /> or <CodeInline text="Disable timer resolution (default).cmd" /> in <CodeInline text="3. General Configuration" /><IconArrow /><CodeInline text="Timer Resolution" />.

## Printing

**When to use:** Disable only if you never print documents or use print-to-PDF workflows.

AtlasOS enables printing by default. Disable it only if you do not use printers or Windows printing features.

To disable printing, run <CodeInline text="Disable Printing.cmd" /> in <CodeInline text="6. Advanced Configuration" /><IconArrow /><CodeInline text="Services" /><IconArrow /><CodeInline text="Printing" /> and restart. To restore the default, run <CodeInline text="Enable Printing (default).cmd" />.

## Search indexing

**When to use:** Enable if you frequently search for files and want faster search results.

Search Indexing speeds up file searches by indexing your files in the background. AtlasOS uses minimal search indexing by default to reduce system overhead.

The Search Indexing folder offers three options: <CodeInline text="Minimal Search Indexing (default).cmd" /> (Atlas default), <CodeInline text="Enable Search Indexing.cmd" /> (full indexing), and <CodeInline text="Disable Search Indexing.cmd" />. Run the appropriate script in <CodeInline text="3. General Configuration" /><IconArrow /><CodeInline text="Search Indexing" /> and restart.

<Callout type="tip">
  Search indexing uses system resources. Only enable if you frequently search for files and need
  faster results.
</Callout>

## Start menu

**When to use:** Install Open-Shell if you prefer a classic Start menu experience.

Customize your Start menu experience with Open-Shell, a tool that provides a customizable classic Start menu.

### Install Open-Shell

1. Run the <CodeInline text="Install Open-Shell.cmd" /> script in <CodeInline text="4. Interface Tweaks" /><IconArrow /><CodeInline text="Start Menu" />
2. Follow the installation prompts
3. Optionally use the <CodeInline text="Atlas Open-Shell Preset.xml" /> file for a pre-configured setup

Learn more about [Open-Shell](https://github.com/Open-Shell/Open-Shell-Menu) and customize it to your preferences.

## System restore

**When to use:** Disable only if you don't need the ability to restore your system to a previous state and want to save disk space.

System Restore uses restore points to roll back some system changes. The Atlas enable script turns on protection for the Windows volume; it does not create a restore point or enable protection on other drives. Check protection and available restore points in Windows before relying on it.

To disable System Restore, run the <CodeInline text="Disable System Restore.cmd" /> script in <CodeInline text="3. General Configuration" /><IconArrow /><CodeInline text="System Restore" /> and restart.

<Callout type="warning">
  Disabling System Restore removes the ability to roll back system changes. Only disable if you're
  confident you won't need this feature.
</Callout>

## Visual effects

**When to use:** Enable if you prefer Windows' visual animations and effects over maximum performance.

Windows includes animated menus, tooltips, and window transitions. Atlas applies a reduced set of effects on a fresh installation. Choose the appearance you prefer; turning off every effect is not required.

To restore Windows visual effects, run the <CodeInline text="Default Windows Visual Effects.cmd" /> script in <CodeInline text="4. Interface Tweaks" /><IconArrow /><CodeInline text="Visual Effects (Animations)" />.
