# Atlas configuration

Configure Atlas. All configuration options live in the Atlas folder on your Desktop or in the Start Menu.

<Callout type="info" title="Missing Atlas folder?">
  If you can't find the Atlas folder, see <AtlasFolderRestoreLink />.
</Callout>

## What you can configure

You can customize:

- **Basic Settings** – Enable or disable Windows features (Bluetooth, Game Mode, notifications)
- **Optional Tweaks** – Context menu styles, Alt-Tab appearance, and more
- **Advanced Options** – Fine-tune system behavior (power users)
- **Security Settings** – Security features and privacy options
- **Windows Settings** – Shortcuts to common Windows configuration

<Callout type="tip">
  Most changes require a restart. A reminder appears when needed.
</Callout>

## Understanding the Atlas folder

The Atlas folder is at <CodeInline text="C:\Windows\AtlasDesktop" />. It holds scripts, registry files, shortcuts, and utilities in numbered sections. The Desktop and Start Menu shortcut opens it.

<DirectoryTree>
C:\Windows\AtlasDesktop
├── 1. Software
├── 2. Drivers
├── 3. General Configuration
├── 4. Interface Tweaks
├── 5. Windows Settings
├── 6. Advanced Configuration
├── 7. Security
├── 8. Additional Tools
└── 9. Troubleshooting
</DirectoryTree>

Each section contains scripts, registry files, shortcuts, or helper utilities. Run the matching file to enable, disable, install, or open the feature you need. Most changes require a restart.

<Callout type="warning" title="Modify with Caution">
  Change settings only if you understand them. Incorrect changes can affect stability or
  functionality. When unsure, check the docs or ask in [Discord](https://discord.com/invite/atlasos).
</Callout>
