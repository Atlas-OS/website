This section explains how to change Atlas and Windows settings after you install Atlas.
Change only what you need; Atlas works without any of these changes.

## Atlas Manager and the Atlas folder

You use two places to manage Atlas after installation:

- **Atlas Manager** shows your installed Atlas version and installation history, and updates or reinstalls Atlas. When you update or reinstall, **Choose again** lets you change your installation choices. Its **Settings** page has **Send a report** and **Export diagnostics**.
- **The Atlas folder** holds a file for each setting you can change, such as Bluetooth, Windows updates or the context menu. Open it from the **Atlas** shortcut on your desktop or in the Start menu, or go to <CodeInline text="%windir%\AtlasDesktop" />.

<Callout type="info" title="Missing Atlas folder?">
  If you can't find the Atlas folder, follow <AtlasFolderRestoreLink />.
</Callout>

## The Atlas folder

<DirectoryTree>
%windir%\AtlasDesktop
├── 1. Software
├── 2. Drivers
├── 3. General Configuration
├── 4. Interface Tweaks
├── 5. Windows Settings
├── 6. Advanced Configuration
├── 7. Security
├── 8. Additional Tools
└── 9. Troubleshooting
</DirectoryTree>

Run the file that names the action you want.
Each file tells you when to restart or sign out.
A file name ending in <CodeInline text="(default)" /> marks what Atlas applies on a first installation, not what's active on your PC.
