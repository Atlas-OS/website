# Atlas folder configuration

The Atlas folder is at <CodeInline text="C:\Windows\AtlasDesktop" />. It holds configuration scripts, registry files, shortcuts, and utilities. The Desktop or Start Menu shortcut opens it.

## Folder structure

<CodeBlock
  title="Folder structure"
  code={`C:\\Windows\\AtlasDesktop
├── 1. Software
├── 2. Drivers
├── 3. General Configuration
├── 4. Interface Tweaks
├── 5. Windows Settings
├── 6. Advanced Configuration
├── 7. Security
├── 8. Additional Tools
└── 9. Troubleshooting`}
/>

Each section contains scripts, registry files, shortcuts, and helper utilities. Double-click the matching file to run it or open the linked settings page. Most changes require a restart to take effect.

<Callout type="tip">
  Scripts marked with <CodeInline text="(default)" /> indicate Atlas's default configuration. Use the paired script without "(default)" to change the setting.
</Callout>

## Section overview

| Section | Description |
|---------|-------------|
| **1. Software** | Install software through WinGet |
| **2. Drivers** | GPU drivers and Windows Update driver options |
| **3. General Configuration** | File sharing, power-saving, updates, Copilot, and more |
| **4. Interface Tweaks** | Visual effects, context menus, File Explorer, Start Menu |
| **5. Windows Settings** | Shortcuts to common Windows configuration pages |
| **6. Advanced Configuration** | Services (Bluetooth, Printing, Network Discovery, NVIDIA Display Container, SuperFetch, SMB), Boot Configuration, Driver Configuration (MSI, Affinity), Microsoft Store, Process Explorer |
| **7. Security** | Defender, mitigations, Core Isolation (VBS) |
| **8. Additional Tools** | Links to HWMonitor, HWiNFO, Everything Search, Autoruns |
| **9. Troubleshooting** | Network reset, Repair Windows Components, Safe Mode, Microsoft Store fixes, and more |

The folder root also contains shortcuts such as Atlas documentation and <CodeInline text="Install AtlasOS Toolbox.cmd" />.

## Sections 8 and 9

The shortcuts in <CodeInline text="8. Additional Tools" /> and <CodeInline text="9. Troubleshooting" /> provide quick access to utilities and recovery options:

### 8. Additional Tools

Links to useful system utilities:

- **HWMonitor** / **HWInfo** - Monitor temperatures, voltages, and system performance
- **Everything Search** - Fast file search (alternative to Windows Search)
- **Autoruns** - View and manage startup programs (Microsoft Sysinternals)

These are shortcuts to download or documentation pages. Install them separately if needed.

### 9. Troubleshooting

Scripts and shortcuts for common recovery tasks:

- **Network** - Reset network settings to Atlas defaults or Windows defaults
- **Repair Windows Components** - Fix corrupted Windows components
- **Set services to defaults** - Restore Atlas services to their default state
- **Fix MS Store Issues** - Repair common Microsoft Store problems
- **Fix File Explorer Visual C++ Runtime Error** - Repair a common Explorer runtime error
- **Fix Errors 2502 and 2503** - Resolve installer permission errors
- **Safe Mode** - Boot into Safe Mode (with or without networking) or exit Safe Mode
- **Telemetry Components** - Manage telemetry-related settings

<Callout type="warning" title="Reset this PC">
  Atlas disables "Reset this PC" because it is unreliable with Atlas modifications. To fully reinstall
  Windows or remove Atlas, follow the [Reverting Atlas](/docs/faq/reverting/) guide.
</Callout>
