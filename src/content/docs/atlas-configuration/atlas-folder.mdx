The Atlas folder holds the files you use to change Atlas and Windows settings after installation.
This page explains how it's organised and how its files work.

Open it from the **Atlas** shortcut on your desktop or in the Start menu.
The folder itself is at <CodeInline text="%windir%\AtlasDesktop" />; you can paste that path into File Explorer's address bar.
If it's missing, follow <AtlasFolderRestoreLink />.

## How the files work

Most files are pairs or small sets that turn one setting on or off, such as <CodeInline text="Enable Gallery.cmd" /> and <CodeInline text="Disable Gallery (default).cmd" />.
Double-click the one you want.
A file asks for administrator permission when it needs it, tells you what it changed, and says when to restart, sign out or restart File Explorer.

<Callout type="tip" title="What (default) means">
  A file name ending in <CodeInline text="(default)" /> marks the setting Atlas applies on a first
  installation. It doesn't tell you which setting is active on your PC: your installation choices
  and later changes decide that.
</Callout>

Atlas records the choice each file applies.
When you update or reinstall Atlas, it applies your recorded choices again, and [Check Atlas health](/docs/atlas-configuration/troubleshooting/#check-atlas-health) reports any that have changed since.
Atlas Toolbox can change many of the same settings.

Updating Atlas replaces the Atlas folder.
Keep your own files somewhere else.

## Shortcuts in the folder

The top of the Atlas folder also holds:

- <CodeInline text="Atlas Documentation" />, which opens these docs.
- <CodeInline text="Atlas Website" />, <CodeInline text="Atlas GitHub" />, <CodeInline text="Atlas Discussions" /> and <CodeInline text="Atlas Discord" />, for news, source code and community help.
- <CodeInline text="Install AtlasOS Toolbox.cmd" />, which installs [Atlas Toolbox](/docs/toolbox/) if you didn't choose it during installation.

Most sections also have a documentation shortcut that opens the matching page of these docs.

## 8. Additional Tools

<CodeInline text="8. Additional Tools" /> holds links to the download pages of free system tools.
Atlas doesn't install them.

- <CodeInline text="Autoruns" />: Microsoft Sysinternals' tool for viewing and managing programs that start with Windows.
- <CodeInline text="Everything Search" />: fast file search by name.
- <CodeInline text="HWInfo" /> and <CodeInline text="HWMonitor" />: temperatures, voltages, fan speeds and other hardware details.

## 9. Troubleshooting

<CodeInline text="9. Troubleshooting" /> holds <CodeInline text="Check Atlas Health.cmd" /> and tools that repair networking, Windows components and Microsoft Store.
See [Troubleshooting tools](/docs/atlas-configuration/troubleshooting/).

To remove Atlas or start again with standard Windows, follow [Reverting Atlas](/docs/faq/reverting/); Atlas doesn't support **Reset this PC**.
