The <CodeInline text="5. Windows Settings" /> folder in the Atlas folder holds shortcuts to Windows settings you might want after installing Atlas.
Each shortcut opens a page in Windows; it doesn't change anything by itself.

Open the Atlas folder from your desktop or the Start menu, or go to <CodeInline text="%windir%\AtlasDesktop" />.
If it's missing, follow <AtlasFolderRestoreLink />.

## Activation

Atlas doesn't activate Windows and doesn't change your activation.
Activate Windows with a valid licence for the edition you installed.
Some personalisation settings stay locked until Windows is activated.

Atlas Manager's **Windows activation** check only informs you.
It doesn't stop installation when Windows isn't activated.

<Callout type="warning" title="Atlas isn't pre-activated Windows">
  Atlas changes your own Windows installation and doesn't include a Windows licence. When you buy
  a licence, make sure the seller is trustworthy and the licence is genuine.
</Callout>

## Hardware-accelerated GPU scheduling

Hardware-accelerated GPU scheduling (HAGS) moves some graphics scheduling work to the graphics card.
Whether it's available depends on your graphics card and driver.
Turning it on doesn't guarantee better performance.

To try it:

1. Install your graphics driver.
2. Open <CodeInline text="Default Graphics Settings (HAGS)" />, then turn on **Hardware-accelerated GPU scheduling** if Windows offers it.
3. Restart your PC.
4. Compare the apps and games you use before and after.

## Keyboard languages

The <CodeInline text="Language" /> shortcut opens the page where you add keyboards and languages.
To change the Alt+Shift and Ctrl+Shift switching shortcuts, see [Keyboard languages](/docs/atlas-configuration/tweaks/#keyboard-languages).
