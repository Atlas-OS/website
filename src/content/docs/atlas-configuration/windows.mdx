# Windows settings

This folder contains shortcuts to common Windows configuration pages. Some settings may require activating Windows first using the "Activation" file.

All configuration files listed here are in the <CodeInline text="5. Windows Settings" /> folder within the Atlas folder on your Desktop. If you can't find the Atlas folder, see <AtlasFolderRestoreLink />.

Running these files opens the corresponding Windows Settings page directly.

## Activation

This file opens the Windows Activation settings page. You may need to activate Windows before changing some other settings.

AtlasOS requires a valid Windows license. Activate Windows with a legitimate license before installation. Activation is a one-time process.

<Callout type="warning" title="Atlas is Not Pre-activated">
  AtlasOS is **not** a pre-activated version of Windows. You must activate Windows with a valid,
  legitimate license before installation.   When purchasing a Windows license, confirm the seller is
  trusted and the license is legitimate.
</Callout>

## Shortcut reference

Each file opens the corresponding Windows Settings page:

| File | Opens |
|------|-------|
| **Colors** | Color and styling options |
| **Date & Time** | Time, date, and time zone settings |
| **Default apps** | Default apps for file types (e.g., browser, media player) |
| **Desktop icons** | Desktop icon visibility (This PC, Recycle Bin, etc.) |
| **Language** | Display and input language |
| **Privacy** | Privacy and diagnostic settings |
| **Region** | Country and region settings |
| **Taskbar** | Taskbar customization |
