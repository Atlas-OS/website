Atlas Toolbox is an optional app for managing your Atlas settings, as an alternative to the launchers in the Atlas folder.
It's in beta, so some features may be unfinished.

## Install Atlas Toolbox

- **While installing Atlas:** select **Install Atlas Toolbox** in the optional extras of Atlas Manager's **Your choices** step.
- **Afterwards:** run `Install AtlasOS Toolbox.cmd` from the top of the Atlas folder, or follow the instructions in the [Atlas Toolbox repository](https://github.com/Atlas-OS/atlas-toolbox).
  You don't need to install Atlas again.

Atlas installs the latest stable Toolbox release.
Toolbox has its own version numbers and releases, so it can be updated without a new Atlas release.
See the [Atlas Toolbox releases](https://github.com/Atlas-OS/atlas-toolbox/releases).

## What it does

- Change Atlas settings from one app instead of running launchers in the Atlas folder.
- Turn Windows features on or off.
- Reach common configuration options quickly.

Atlas Toolbox changes settings through the same Atlas toggles as the Atlas folder, so Atlas records your changes and keeps them when you update.

## Remove Atlas Toolbox

Uninstall it from **Installed apps** in Windows Settings.
Atlas doesn't uninstall apps it installed, even if you choose again when you update Atlas.
