The Atlas Toolbox is a graphical utility for AtlasOS. It offers an alternative to the Atlas folder for configuring settings.

## Installation

Select **Install Atlas Toolbox** in Atlas Manager or AME Wizard during setup. Atlas downloads the latest stable Toolbox release, which is versioned separately from the playbook. If you skipped it, follow the installation instructions in the [Atlas Toolbox repository](https://github.com/Atlas-OS/atlas-toolbox); you do not need to rerun Atlas setup.

## Features

- Configure Atlas settings via a graphical interface
- Manage Windows features and optimizations
- Quick access to common configuration options
