# Atlas Toolbox

The Atlas Toolbox is a graphical utility for AtlasOS. It offers an alternative to the Atlas folder for configuring settings.

## Installation

Install the Toolbox during Atlas installation by selecting **Install Atlas Toolbox** in AME Beta. If you skipped it, re-run the Atlas Playbook and select the Toolbox option, or install manually from the [Atlas Toolbox repository](https://github.com/Atlas-OS/atlas-toolbox).

## Features

- Configure Atlas settings via a graphical interface
- Manage Windows features and optimizations
- Quick access to common configuration options
