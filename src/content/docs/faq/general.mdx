## Checking your AtlasOS version

Windows Settings does not show the Atlas version. Use these checks:

1. **Check the Playbook file:** If you kept the <CodeInline text=".apbx" /> file used for installation, read the version in its filename, such as <CodeInline text="Atlas Playbook 0.5.x" />
2. **Compare the installation date:** Find the Atlas release published immediately before your installation date on the [releases page](https://github.com/Atlas-OS/Atlas/releases)
3. **Check the Atlas folder:** Open <CodeInline text="C:\Windows\AtlasDesktop" /> and look for a version reference in its scripts

## Performance

### Will AtlasOS improve my gaming performance?

Atlas includes optimizations that may improve gaming performance by reducing background processes and system overhead. Results vary by hardware and usage.

### How much faster is AtlasOS?

Performance improvements vary by hardware and usage. Many users report:

- Reduced RAM usage
- Lower CPU overhead
- Faster boot times
- Improved gaming frame rates

### What optimizations does AtlasOS include?

Atlas applies privacy, usability, and performance tweaks:

- Removes telemetry and unnecessary services
- Optimizes system processes
- Disables background tasks
- Improves resource allocation

## Compatibility

### Can I use Windows Store apps?

Yes, Windows Store apps work normally with AtlasOS.

Most Windows software works with Atlas. Some enterprise software may require specific Windows features that Atlas has optimized.

### Can I use Windows Update?

Yes. Configure Windows Update and driver updates from the Atlas folder.

## Enabling TPM

Windows 11 requires **Trusted Platform Module (TPM) 2.0**. If Windows Setup reports that your PC does not meet the requirements, check TPM in your BIOS or UEFI.

<Callout type="warning" title="Proceed with caution">
  Modifying BIOS/UEFI settings incorrectly can cause system instability. Only change settings you
  understand. Consult your motherboard or manufacturer's documentation if unsure.
</Callout>

### Steps

1. **Open the BIOS or UEFI:** Restart the computer and repeatedly press the setup key shown in your manual or startup screen. Common keys include <CodeInline text="DEL" />, <CodeInline text="F2" />, <CodeInline text="F10" />, <CodeInline text="F12" />, and <CodeInline text="ESC" />.

2. **Find the TPM setting** - Look in sections like Security, Advanced, Trusted Computing, or CPU Configuration. Setting names may include:
   - <CodeInline text="TPM" /> / <CodeInline text="TPM Device" /> / <CodeInline text="TPM State" />
   - **Intel CPUs:** <CodeInline text="PTT" /> (Platform Trust Technology)
   - **AMD CPUs:** <CodeInline text="fTPM" /> or <CodeInline text="AMD fTPM switch" />

3. **Enable TPM** - Change from <CodeInline text="Disabled" /> to <CodeInline text="Enabled" /> (or <CodeInline text="On" /> / <CodeInline text="Available" /> / <CodeInline text="Firmware TPM" />).

4. **Save and exit** - Use Save Changes and Exit (often <CodeInline text="F10" />), then retry the Windows installation.

## Security and AtlasOS

Atlas lets you configure Windows Defender, [mitigations](/docs/atlas-configuration/security/#mitigations), and automatic Windows updates. Review each tradeoff in the [security documentation](/docs/atlas-configuration/security/) before changing a default.

**Compared with unmodified Windows:** Modifying Windows changes its tested security baseline. Review the [Atlas source](https://github.com/Atlas-OS/Atlas) and AME Beta's [open-source backend](https://github.com/Ameliorated-LLC/trusted-uninstaller-cli) before you install.

**Legacy versions (v0.4.1 and earlier):** Not direct upgrade sources for the current Playbook. [Reinstall Windows and install Atlas](/docs/install/requirements/) unless a specific archived upgrade path is published for your exact version. Newer versions add Windows Update, Defender, UAC by default, Core isolation, and improved transparency.

## Resetting Atlas

The Windows "Reset this PC" feature **doesn't work** with Atlas. Atlas makes deep changes that Reset cannot handle—it will likely fail or leave your system broken.

**To start fresh with Atlas:** Follow the [Installation Guide](/docs/install/requirements/) (clean install).

**To remove Atlas:** Follow the [Reverting Atlas](/docs/faq/reverting/) guide.

## Game troubleshooting

### Roblox not launching

1. **Change time and date:** **Settings**<IconArrow />Date & time - turn off "Set time automatically", add one day to the date, then re-enable automatic time after a day.
2. **Enable TPM and Secure Boot** in BIOS.
3. **Enable UAC:** **Control Panel**<IconArrow />Change User Account Control settings - set to Level 1, 2, or 3. If UAC was disabled (Level 0), reinstall Roblox after enabling it.

### FIFA and EAFC not launching

FIFA and EAFC require Windows Defender to be enabled. Open the Atlas folder, go to <CodeInline text="7. Security" /><IconArrow /><CodeInline text="Defender" />, and run <CodeInline text="Toggle Defender.cmd" />.

## AtlasOS and eclean

[eclean](https://eclean.gg/) is a Windows maintenance app built by the Atlas team. Atlas transforms Windows once when you apply the Playbook. eclean handles the upkeep afterward: cleaning junk files, managing startup apps, and applying optimizations. Every change is explained before it happens, and supported changes can be undone.

### Do I need eclean to use AtlasOS?

No. Atlas never requires, depends on, or checks for eclean.

### Does eclean work on AtlasOS?

Yes. Atlas does not maintain anything after installation, and eclean is the tool we recommend for ongoing upkeep. The two are designed to work alongside each other without conflicts. For built-in tools and other options, see [Maintenance](/docs/essential-setup/maintenance/).

## Microsoft Store

The Microsoft Store works the same as on unmodified Windows. If you have issues, they are usually unrelated to Atlas. Try:

1. Press **Win + R**, type <CodeInline text="wsreset -i" />, press **Enter**
2. Open Microsoft Store, go to **Downloads and Updates**, wait for it to update
