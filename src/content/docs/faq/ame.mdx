## What is AME Wizard?

AME Wizard, also labelled AME Beta, applies playbook packages to Windows. You can use it as an [alternative installer](/docs/install/ame-wizard/) for Atlas 0.6. [Atlas Manager](/docs/install/playbook/) is the recommended setup app and does not require Wizard.

## AME Beta deleted or closed suddenly

Check Windows Security's protection history to see what blocked or removed the file. Confirm that you downloaded Wizard from [Ameliorated](https://amelabs.net/). A detection alone does not establish whether a file is safe; do not add broad exclusions or assume every warning is a false positive.

Follow the publisher's guidance for the exact detection. If you cannot resolve it, use Atlas Manager or ask for help with the detection details.

## Why is AME Beta being flagged?

Tools that apply system changes can trigger security detections. Check the file's source and the reported detection before deciding what to do. The [Ameliorated documentation](https://docs.amelabs.net/using-wizard/running-playbook.html) covers Wizard's installation requirements.

## Installation issues

### AME Beta won't open

Check the error, confirm the download is complete, and allow administrator access when requested. If antivirus blocked it, check protection history as described above.

### Upgrade option not available

Atlas 0.6 declares upgrades from 0.4.1, 0.5.0, and 0.5.1, separately requiring Windows 11 25H2 (build 26200). Confirm both versions and the selected package against [Before upgrading](/docs/upgrade/requirements/). Use an up-to-date Wizard. Reapplying a package does not bypass these requirements.

### Installation fails

Read Wizard's error and keep the logs before retrying. Confirm that Windows and Store updates are complete, required restarts have finished, and no other installer is running. If the failure occurred while applying changes, the installation may be incomplete.

### "This Windows build is not supported"

Run `winver` to check the build. Atlas 0.6 requires 25H2, build 26200. Installing every update offered for an older Windows release does not necessarily move it to that build. Follow the [requirements](/docs/install/requirements/).

### "Cannot disable Defender" or "Cannot open Windows Defender settings"

Check the Windows Security state and the reported error. A policy, missing component, or previous modification may need attention. Do not repeatedly bypass the check. Save the logs and report the problem if the guided steps cannot resolve it.

### "Reticulating Splines" or "Action taking a long time"

A progress message that has not changed does not prove installation has stopped. Open **Show logs** and inspect the latest output. Keep the PC powered on while an operation is running; do not end a servicing process in Task Manager to force progress.

If the operation fails or appears stuck, save the logs and [report the issue](/docs/contributing/reporting/). Include the last visible stage, elapsed time, and whether the log continues to change.

## Which logs should I share?

Wizard logs are under `C:\ProgramData\AME\Logs`. Include the relevant `Output.txt` and `Log.yml`, after reviewing them for personal information. If Atlas Manager is available, also use **Export diagnostics** to collect Atlas installation evidence.
