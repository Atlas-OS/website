Use this guide if your PC runs Windows 11 Home and Atlas Manager says **Windows 11 Home, LTSC and Server editions aren't supported**.
Atlas Manager checks your Windows edition even if you already have Atlas installed.

## Check your Windows edition

Open **Settings** > **System** > **Activation** and check the edition at the top of the page.
If it shows **Windows 11 Home**, choose how to move to Pro.

- [Upgrade in Settings](#upgrade-windows-home-to-pro-in-settings) to keep your files and apps. You can use a Pro product key or try the generic Pro setup key.
- [Reinstall from an Atlas USB](#reinstall-windows-as-pro) if the Settings upgrade fails or Atlas requires a fresh installation.

If Windows already shows a supported edition, restart your PC and open Atlas Manager again.
If the edition error returns, [send a report](/docs/faq/report-a-problem/) with the edition shown in Settings.
If your work or school provides Enterprise or Education, ask its IT team which edition and licence to use.
See [Windows edition requirements](/docs/install/requirements/#windows-edition).

## Upgrade Windows Home to Pro in Settings

Changing editions through Settings keeps your files and installed apps.
Back up important files first and check that Home is activated under **Activation state**.

If you have a Pro product key, use it in the steps below.
To try changing editions before activating Pro, use the generic Windows Pro setup key `VK7JG-NPHTM-C97JM-9MPGT-3V66T`.
Use a Pro product key or digital licence to activate afterwards.

1. If you're using the generic key, turn off Wi-Fi and unplug any Ethernet cable before you continue.
2. On **Activation**, expand **Upgrade your edition of Windows** if it appears.
3. Next to **Change product key**, select **Change**.
4. Enter the key and select **Next**.
5. Follow the prompts and restart when Windows asks.
   If you disconnected from the internet, reconnect after the restart.

If Windows rejects the generic key, try your Pro product key or [reinstall Windows as Pro](#reinstall-windows-as-pro).
See [Microsoft's Home-to-Pro instructions](https://support.microsoft.com/en-gb/windows/deployment/install-upgrade/upgrade-windows-home-to-windows-pro) and [Microsoft Q&A guidance on the generic key](https://learn.microsoft.com/en-us/answers/questions/5913947/error-code-0xc004f050-windows-11-home-with-digital).

## Reinstall Windows as Pro

Back up your files to a separate drive or cloud storage before you reinstall.

Start from the installation USB to choose Pro on a PC that still runs Home.
The [mounted ISO route](/docs/install/iso/#reinstall-without-a-usb-drive) uses the same edition that's already installed.

1. Open Atlas Manager and choose **Create an Atlas ISO**.
   On the **Setup** step, choose **Change** under **Windows edition**, then **Windows 11 Pro**. [Create an Atlas ISO](/docs/install/iso/)
2. Write the ISO to a USB drive and start the PC from it. [Install from a USB drive](/docs/install/iso/#install-from-a-usb-drive)
3. If Windows Setup asks for a product key, enter your Pro key or choose **I don't have a product key** to activate later.
4. Select **Windows 11 Pro** if Setup asks for an edition, then finish installing Windows.

## Activate Windows 11 Pro

After Windows starts, open **Settings** > **System** > **Activation** and confirm it shows **Windows 11 Pro**.
Activate Pro from this page using your product key or digital licence. [Microsoft's Windows activation instructions](https://support.microsoft.com/en-gb/windows/activation/activate-windows)
Atlas Manager can continue past the edition check while Windows activation is pending.

## Continue in Atlas Manager

If you reinstalled Windows, [finish installing Atlas](/docs/install/iso/#5-finish-installing-atlas).
If you changed editions in Settings and already have Atlas installed, reopen Atlas Manager and check whether your version can update. [Before updating Atlas](/docs/upgrade/requirements/)

- If Atlas Manager offers **Update to Atlas**, follow the [update instructions](/docs/upgrade/upgrade/).
- If Atlas Manager requires a fresh Windows installation, [reinstall Windows as Pro](#reinstall-windows-as-pro).

For a first-time Atlas installation, check the [fresh Windows requirements](/docs/install/requirements/#start-with-fresh-windows).
