To remove Atlas, perform a **clean Windows installation using unmodified Microsoft media**. Reset this PC, an in-place repair, and deleting Atlas Manager are not supported ways to undo all Atlas changes.

<Callout type="warning" title="Use Microsoft media">
  An ISO or USB prepared by Atlas Manager includes Atlas setup. Use Microsoft's Windows media
  for this process, otherwise Atlas setup can start again after Windows is installed.
</Callout>

If you want to keep Atlas and resolve a problem, start with [troubleshooting](/docs/faq/installation/) or [report an issue](/docs/contributing/reporting/). To reinstall Atlas instead, follow the [installation guide](/docs/install/).

## 1. Prepare your backup

Copy personal files, game saves, application settings, and any recovery keys you need to storage outside the installation drive. Open a few backed-up files to check them. A restore point is not a substitute for this backup.

Note your Windows edition and activation status in **Settings → System → Activation**. Reinstall the edition covered by your license. Keep access to any accounts and application licenses needed afterwards.

Download a network driver for your exact PC or motherboard from its manufacturer's support page and save it separately. Choose the package matching your Windows architecture; you do not need every listed driver version. See [network drivers](/docs/essential-setup/drivers/network/).

## 2. Create Windows installation media

Use [Microsoft's installation-media guide](https://support.microsoft.com/en-us/windows/deployment/install-upgrade/create-installation-media-for-windows) and official downloads. Check **Settings → System → About → System type** to select the correct architecture.

Use an empty USB drive that meets the tool's requirements. Creating installation media erases that USB, so keep your backup on another drive.

## 3. Start a clean installation

Boot from the USB and follow the **clean installation** section of [Microsoft's reinstall guide](https://support.microsoft.com/en-us/windows/deployment/install-upgrade/reinstall-windows-with-the-installation-media).

<Callout type="danger" title="Check the destination drive">
  Deleting partitions erases their contents. Identify the Windows destination by its size and
  disk details before deleting anything. Do not assume a disk number identifies the correct drive.
  If you cannot identify it confidently, stop before changing partitions.
</Callout>

Disconnect backup storage before starting installation. Where practical, disconnect other drives to reduce the chance of selecting the wrong one. Follow your device manufacturer's instructions for opening its boot menu.

## 4. Complete Windows setup

Follow the account, network, and privacy prompts on screen. The sequence can vary by Windows edition and release; use the prompts supplied by your installation media.

At the desktop, check activation, install Windows updates and needed drivers, then restore your files and applications. See [Microsoft's driver-update instructions](https://support.microsoft.com/en-us/windows/hardware/drivers/automatically-get-recommended-and-updated-hardware-drivers).

Your PC now runs standard Windows. You do not need to reinstall Atlas Manager or apply a playbook.
