## Quick answers

### What is AtlasOS?

AtlasOS is an open-source modification of Windows that applies privacy, usability, and performance optimizations while keeping functionality and customizability.

### Is AtlasOS safe?

AtlasOS publishes its source code and Playbook changes on GitHub for public review. Review those changes and the [security configuration](/docs/atlas-configuration/security/) before deciding whether Atlas fits your needs.

### Which Windows versions are supported?

Atlas supports **Windows 11** Pro, Pro for Workstations, and Enterprise.

<Callout type="warning" title="Windows Home is not supported">
  Change your product key to upgrade Windows to Pro before you install Atlas.
</Callout>
