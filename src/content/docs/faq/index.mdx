## Quick answers

### What is AtlasOS?

AtlasOS is an open-source project that configures Windows for privacy, usability and performance, while keeping Windows features available.

### Is AtlasOS safe?

AtlasOS publishes its source code on GitHub, including every change it makes to Windows.
Review those changes and the [security settings](/docs/atlas-configuration/security/) before you decide whether Atlas suits you.

### Which Windows versions are supported?

Atlas supports public releases of Windows 11 listed in the [supported releases table](https://github.com/Atlas-OS/Atlas/blob/main/docs/windows-release-policy.md#supported-releases), in editions such as Pro, Education and Enterprise.
See [Before you install](/docs/install/requirements/).

<Callout type="warning" title="Windows 11 Home isn't supported">
  Windows 11 Home, LTSC and Server editions can't take Atlas.
  Use an edition such as Pro that you have a Windows licence for.
</Callout>
