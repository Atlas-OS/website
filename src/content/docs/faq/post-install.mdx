# Post-install FAQ

Find the Atlas folder, install drivers, and restore common settings after installation.

## Atlas folder

### Where is the Atlas folder?

The Atlas folder is at <CodeInline text="C:\Windows\AtlasDesktop" />. It also appears on your Desktop or in the Start Menu.

### I can't find the Atlas folder

If you can't find the Atlas folder, see <AtlasFolderRestoreLink samePage={true} /> below.

### Restoring the Atlas folder

First, check whether the shortcut or the folder itself is missing.

**If only the Desktop shortcut is missing:** Open <CodeInline text="C:\Windows" /> in File Explorer. Right-click <CodeInline text="AtlasDesktop" />, then select **Send to**<IconArrow />**Desktop (create shortcut)**.

**If <CodeInline text="C:\Windows\AtlasDesktop" /> is missing:** Download the latest [Atlas Playbook](https://atlasos.net) and [AME Beta](https://ameliorated.io/). Open AME Beta and drag the Playbook into it to restore the folder without reinstalling Windows.

### What's in the Atlas folder?

The Atlas folder contains configuration files, scripts, and utilities for customizing your AtlasOS installation:

- Configuration files for tweaks and settings
- Scripts to enable/disable features
- Windows Settings shortcuts
- Driver installation options

## Drivers

### Do I need to install drivers manually?

Follow the driver method you chose during installation:

- **Windows Update method**: Drivers install automatically
- **Manual method**: Install drivers manually

See the [Drivers Guide](/docs/essential-setup/drivers/) for detailed instructions.

### Which drivers do I need?

Essential drivers typically include:

- Graphics (GPU)
- Network/Wi-Fi
- Audio
- Bluetooth (if needed)
- Chipset (recommended)

## Configuration

### How do I enable Bluetooth?

Bluetooth is enabled by default in the current Atlas folder. If you disabled it and want to restore the default:

1. Open the Atlas folder
2. Go to <CodeInline text="6. Advanced Configuration" /><IconArrow /><CodeInline text="Services" /><IconArrow /><CodeInline text="Bluetooth" />
3. Run <CodeInline text="Enable Bluetooth (default).cmd" />
4. Restart your computer

### How do I enable Windows Update for drivers?

1. Open the Atlas folder
2. Go to <CodeInline text="2. Drivers" /><IconArrow /><CodeInline text="Drivers from Windows Update" />
3. Run the appropriate script to enable Windows Update driver installation
4. Restart your computer

### How do I restore Windows visual effects?

1. Open the Atlas folder
2. Go to <CodeInline text="4. Interface Tweaks" /><IconArrow /><CodeInline text="Visual Effects (Animations)" />
3. Run <CodeInline text="Default Windows Visual Effects.cmd" />
