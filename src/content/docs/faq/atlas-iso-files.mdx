# Where is the Atlas ISO file?

**Atlas doesn't have a modified ISO file for users to download directly.**

Distributing ISO files violates Microsoft's terms and poses **major safety risks** because there is no easy way to verify that modified third-party ISOs are not malicious.

<Callout type="info" title="Microsoft policy">
"For software downloads, unless expressly permitted in the accompanying License Terms or End-User License Agreement (EULA), Microsoft does not allow redistribution. You may link to the download page, but not directly to the download, from your product or website." - [Microsoft Permissions](https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions)
</Callout>

## How does Atlas work then?

You get Atlas by using [AME Beta](https://ameliorated.io/), which modifies a stock Windows ISO (or modifies Windows on a live installation). See the [installation guide](/docs/install/requirements/).

## What does the ISO downloader do?

The ISO download instructions describe how to obtain **unmodified** Windows ISOs from Microsoft. See the [Playbook guide](/docs/install/playbook/#step-1-download-windows-iso) or [ISO injection guide](/docs/install/iso/#step-1-download-windows-iso).
