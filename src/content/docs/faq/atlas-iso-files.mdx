Atlas does not distribute premodified Windows ISO files. Get unmodified Windows media from Microsoft, then use one of these routes:

- **[Install with Atlas Manager](/docs/install/playbook/):** Install fresh Windows first, then let Manager prepare and apply Atlas.
- **[Create an Atlas ISO](/docs/install/iso/):** Use Manager's beta media tools to include the app, playbook, and optional saved settings in your own ISO.
- **[Install with AME Wizard](/docs/install/ame-wizard/):** Apply the Atlas playbook through the alternative installer.

## Is Atlas already installed inside a Manager-created ISO?

The ISO contains the setup files. Atlas is applied on the destination PC after Windows setup and sign-in, so Manager can check Windows and Store updates for the account using it. Internet access and security checks are still required, including in the before-desktop setup mode.

## Which Windows ISO should I use?

For Atlas Manager's ISO creation, use an unmodified **Windows 11 25H2 x64 ISO** containing a supported edition. Manager checks the release and included editions before building. See the [media guide](/docs/install/iso/#1-choose-your-files) for the full requirements.
