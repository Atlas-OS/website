Atlas doesn't distribute ready-made Windows ISO files.
Get Windows 11 from Microsoft, then choose one of these routes:

- **[Create an Atlas ISO](/docs/install/iso/) (recommended):** use Atlas Manager to make a copy of Microsoft's ISO with Atlas Manager, Atlas and, if you like, your choices added.
- **[Install with Atlas Manager](/docs/install/manager/):** install Windows from Microsoft's media first, then let Atlas Manager update Windows and install Atlas.

## Is Atlas already installed inside an Atlas ISO?

No.
The ISO contains the files Atlas needs.
Atlas installs on the destination PC after Windows setup and your first sign-in, so Atlas Manager can update Windows and Store apps for the account that uses it.
That PC still needs an internet connection and the Windows Security step, even with **Finish setup before the desktop**.

## Which Windows ISO should I use?

Use Microsoft's Windows 11 ISO for a [supported release](https://github.com/Atlas-OS/Atlas/blob/main/docs/windows-release-policy.md#supported-releases), x64 or Arm64.
**Download Windows 11 from Microsoft** on Atlas Manager's **Files** step opens Microsoft's download page.
Atlas Manager checks the release and the editions in the ISO before it builds.
See [Create an Atlas ISO](/docs/install/iso/#what-you-need) for the full requirements.
