# Where is the Atlas ISO file?

**Atlas does not distribute modified Windows ISO files.**

Microsoft restricts redistribution of Windows downloads. Modified third-party ISOs also create a security risk because you cannot easily verify every change they contain.

<Callout type="info" title="Microsoft policy">
"For software downloads, unless expressly permitted in the accompanying License Terms or End-User License Agreement (EULA), Microsoft does not allow redistribution. You may link to the download page, but not directly to the download, from your product or website." - [Microsoft Permissions](https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions)
</Callout>

## Install Atlas without a modified ISO

Use [AME Beta](https://ameliorated.io/) to apply the Atlas Playbook to a stock Windows ISO or a live Windows installation. Start with the [installation requirements](/docs/install/requirements/).

## What does the ISO downloader do?

The ISO downloader helps you obtain an **unmodified** Windows ISO from Microsoft. Follow the [Playbook download steps](/docs/install/playbook/#step-1-download-windows-iso) or [ISO injection download steps](/docs/install/iso/#step-1-download-windows-iso).
